\Chapter{Operations Involving the Natural Numbers}
\Lettrine[loversize=0.1,nindent=0pt]{What} is the point of having numbers but with no way to interact with them? Numbers without any relationships defined between them are useless to us; we need operations between them to create relationships between them. This chapter will introduce two well-defined operations: addition and multiplication.

\section{Binary Operations}
To define the operations on the natural numbers, we first need to understand what ``operation'' means. In particular, we are only looking at binary operations.

\begin{definition}[Binary Operation]
    A \term{binary operation on a set $S$}\index{operation}\index{operation!binary}\index{binary operation} is a function $f: S \times S \to S$ (i.e., $f: S^2 \to S$).
\end{definition}
\begin{remark}[$n$-ary Operation]
    We can generalize the definition of an operation to be an \term{$n$-ary operation on a set $S$}\index{operation!$n$-ary}, which is a function $f: S^n \to S$ where $n \in \N$. We will stick to the case when $n = 2$ for this chapter.
\end{remark}

It should be noted that we usually use infix notation to write binary operations.

\begin{example}[Union Operation]
    \setlength{\parindent}{1.5em}
    
    Let $A$ be a set. We can define the set union operation on the set $A$ by the function $u: \Power{A} \times \Power{A} \to \Power{A}$ where
    \[
        u(S, T) = \{x \in A \vert x \in S \lor x \in T\}
    \]
    for all $S, T \in \Power{A}$. Note that $u(S, T)$ would be written as $S\mathrel{u}T$ using infix notation.

    For example, for the set $A = \{1, 2, 3, 4, 5\}$, $S = \{1, 2\}$ and $T = \{2, 3\}$, we see that
    \[
        u(S, T) = S\mathrel{u}T = \{1, 2, 3\}.
    \]
    If instead $S = \{1, 4, 5\}$ and $T = \{2, 3, 5\}$ one notes that
    \[
        S\mathrel{u}T = \{1, 2, 3, 4, 5\} = A.
    \]
\end{example}

\begin{example}[Intersection Operation]
    \setlength{\parindent}{1.5em}

    Likewise, we can define the set intersection operation on a set $A$ by the function $n: \Power{A} \times \Power{A} \to \Power{A}$ where
    \[
        S \mathrel{n} T = \{x \in A \vert x \in S \land x \in T\}
    \]
    for all $S, T \in \Power{A}$.

    For example, for the set $A = \{1, 2, 3, 4, 5\}$, we see that
    \[
        \{1,2\}\mathrel{n}\{2,3\} = \{2\}.
    \]
    and
    \[
        \{1, 3, 5\}\mathrel{n}\{2, 4\} = \emptyset.
    \]
\end{example}

\begin{example}[Function Composition Operation]
    Let $S$ be a set, and let $\mathcal{F}$ denote the set of all functions $f$ from $S$ to $S$. We can then define an operation $o: \mathcal{F}^2 \to \mathcal{F}$ such that
    \[
        o(f, g) = f \circ g
    \]
    for all $f, g \in \mathcal{F}$, i.e. $o$ acts like function composition.
\end{example}

\begin{exercise}[Set Difference]
    Let $A$ be a set. Write down a definition for the set difference operation on the set $A$.
\end{exercise}

\section{Axiom of Induction}
Earlier, in \myref{section:basics-of-induction}, we covered the basics of mathematical induction. However, so far, there has not been an explicit axiom proving that mathematical induction works as a proof technique.

Why does this matter?

Let $P(n)$ be a predicate that is defined for all natural numbers. Suppose $P(0)$ is true, and that if $P(k)$ is true then $P(k+1)$ (which really should be written as $P(\Successor{k})$ for now) is true for all $k \in \N$. One clearly sees that $P(0)$ being true implies $P(1)$ being true, which thus means $P(2)$ is true, which thus means $P(3)$ is true, and so on. But at no point can we assert that $P(n)$ is true for all $n \in \N$! Each $P(n)$ can be proven using a finite number of steps, but to prove all of them requires an infinite number of steps, which we cannot perform.

But clearly mathematical induction (as stated above) clearly works! It is a very useful (and clever) proof technique that allows us to evade proving each case of $P(n)$ manually. And yet we cannot prove it using the tools that we have so far. Thus, we need an additional axiom.

The \term{axiom of induction} is \textbf{not} an axiom of \ZFC. Rather, it can be seen as an axiom of logic when working with the natural numbers. However, to state it, we will appeal to the notation used in \ZFC, although it would not be in the formal language of axiomatic set theory.

\begin{axiom}[Induction]\index{axiom!of induction}\label{axiom:induction}
    \vspace{-10px}
    \[
        \forall A, \left((0 \in A) \land (\forall k \in \N, (k \in A \implies \Successor{k} \in A)) \implies \N \subseteq A\right)
    \]
\end{axiom}

Essentially, this axiom is the same as what we have covered in \myref{section:basics-of-induction}. In the axiom, the set $A$ can be thought of as the set containing elements satisfying our desired predicate $P(n)$. For the consequent of the axiom to hold, it requires two conditions.
\begin{itemize}
    \item \textbf{Base Case}: $0 \in A$, i.e. the statement $P(0)$ must be true.
    \item \textbf{Induction Step}: For all natural numbers $k$, if $k \in A$ then $\Successor{k} \in A$, i.e. if $P(k)$ is true for some $k$ then $P(\Successor{k})$ (which is the same as $P(k+1)$) is also true.
\end{itemize}
If both these conditions hold, then we know that all of the natural numbers belong in $A$ (i.e., $P(n)$ is true for all $n \in \N$).

The axiom of induction is needed to prove the properties of the operations on the natural numbers.

\section{Addition}
Intuitively, addition is the simplest operation on the natural numbers. How hard can it be to add two numbers together? However, as we will see, creating a proper definition of addition will take some work.

\subsection{Basic Definitions}
Let us first define what addition is. We know that addition can be thought of as a binary operation on $\N$, but that isn't that helpful. What we want to do is to find properties that this operation must satisfy.

We can probably all agree that adding zero to any natural number should just return the number. It should be the case that $3 + 0 = 3$, just like how $42 + 0 = 0$, $101 + 0 = 101$, and $7125 + 0 = 7125$. So that should be the first property that addition must satisfy: adding zero to any natural number is just that natural number.

A less obvious property that addition has to satisfy is adding with successors. Consider $3 + \Successor{4}$. Intuitively, we know that $\Successor{4} = 4 + 1 = 5$, and so $3 + \Successor{4} = 3 + 5 = 8$. Notice, however, that we can also write $3 + \Successor{4}$ as $\Successor{3 + 4} = (3 + 4) + 1 = 8$. This is the second thing that addition has to satisfy: adding a successor of a number to another number is the successor of the sum of the two numbers.

With these two properties, we can create a definition for addition.

\begin{definition}[Addition]
    The \term{addition operation}\index{addition} is the function $+: \N^2 \to \N$ such that
    \begin{enumerate}[label=\textbf{A\arabic*.}]
        \item for all $n\in \N$ we have $n + 0 = n$; and
        \item for all $n, d \in \N$ we have $n + \Successor{d} = \Successor{n + d}$.
    \end{enumerate}
\end{definition}

Surprisingly, these two conditions on the addition operation are all we need to define the rest of the properties of addition.

\subsection{Basic Properties of Addition}
The first result should be very obvious.

\begin{proposition}[Successor of $n$]\label{prop:successor-of-n}
    $\Successor{n} = n + 1$ for all $n \in \N$.
\end{proposition}
\begin{proof}
    See \myref{exercise:successor-of-n} (later).
\end{proof}

\begin{exercise}[Successor of $n$]\label{exercise:successor-of-n}
    Prove \myref{prop:successor-of-n}.\newline
    (\textit{Note: recall that we define $\Successor{0} = 1$.})
\end{exercise}

The next result should also be obvious, but its proof is more involved.
\begin{lemma}[Sum of 0 and $n$]\label{lemma:sum-of-0-and-n}
    $0 + n = n$ for all $n \in \N$.
\end{lemma}
Notice that \textbf{A1} only works for $n + 0$, not $0 + n$. That is why we need to prove this as a separate lemma.
\begin{proof}
    We induct on $n$.

    For the base case $n = 0$, one clearly sees that $0 + 0 = 0$ by \textbf{A1}.

    Now suppose the statement holds for some natural number $k$, i.e. $0 + k = k$. We are to prove that the statement holds for the successor of $k$, i.e. $0 + \Successor{k} = \Successor{k}$.

    Let's start with $0 + \Successor{k}$. By \textbf{A2}, we know that it is the same as $\Successor{0 + k}$. Using the induction hypothesis we can immediately rewrite this as $\Successor{k}$, which is what we wanted to show. Thus the statement also holds for $\Successor{k}$

    By induction (via the axiom of induction (\myref{axiom:induction})), we have proven this proposition.
\end{proof}

The following result is the `reversed' version of \textbf{A2}.

\begin{lemma}[Sum of $\Successor{d}$ and $n$]\label{lemma:sum-of-successor-and-n}
    $\Successor{d} + n = \Successor{d + n}$ for all $n, d \in \N$.
\end{lemma}
\begin{proof}
    See \myref{exercise:sum-of-successor-and-n} (later).
\end{proof}

We are now ready to prove the commutativity of addition.

\begin{theorem}[Commutativity of Addition (Naturals)]\index{addition!commutativity}\label{theorem:addition-commutative-naturals}
    $m + n = n + m$ for all $m, n \in \N$.
\end{theorem}
\begin{proof}
    Take $m$ as an arbitrary natural number. We will induct on $n$.

    For the base case, the left-hand side is $m + 0$ which is $m$ by \textbf{A1}. The right-hand side is $0 + m$ which is also $m$ by \myref{lemma:sum-of-0-and-n}. Thus the two sides are equal, proving the base case.

    Suppose that $m + k = k + m$ for some $k \in \N$. We will prove that $m + \Successor{k} = \Successor{k} + m$.

    One sees that
    \begin{align*}
        m + \Successor{k} &= \Successor{m + k} & (\text{by \textbf{A2}})\\
        &= \Successor{k + m} & (\text{induction hypothesis})\\
        &= \Successor{k} + m & (\text{by \myref{lemma:sum-of-successor-and-n}})
    \end{align*}
    which proves the case for $\Successor{k}$.
\end{proof}

\begin{exercise}[Sum of $\Successor{d}$ and $n$]\label{exercise:sum-of-successor-and-n}
    Prove \myref{lemma:sum-of-successor-and-n}.
\end{exercise}

We can now also prove the associativity of addition.

\begin{theorem}[Associativity of Addition (Naturals)]\index{addition!associativity}\label{theorem:addition-associative-naturals}
    $(a + b) + c = a + (b + c)$ for all $a,b,c \in \N$.
\end{theorem}
\begin{proof}
    Let $a$ and $b$ be arbitrary natural numbers. We induct on $c$.

    For the base case $c = 0$, the left-hand side is $(a + b) + 0$. \textbf{A1} allows us to rewrite this as $a+b$. On the other hand, the right-hand side is $a + (b + 0)$ which \textbf{A1} again allows us to rewrite as $a + b$. Thus the base case is proven.

    Suppose that $(a + b) + k = a + (b + k)$ for some $k \in \N$. We show that $(a + b) + \Successor{k} = a + (b + \Successor{k})$.

    One sees clearly that
    \begin{align*}
        (a + b) + \Successor{k} &= \Successor{(a + b) + k} & (\text{by \textbf{A2}})\\
        &= \Successor{a + (b + k)} & (\text{induction hypothesis})\\
        &= a + \Successor{b + k} & (\text{by \textbf{A2}})\\
        &= a + (b + \Successor{k}) & (\text{by \textbf{A2}})
    \end{align*}
    which proves the case for $\Successor{k}$.
\end{proof}

Since addition is associative, we can just write expressions like $a + b + c$ without any ambiguity.

There is a useful corollary from these two theorems.

\begin{corollary}\label{corollary:right-commutativity-of-addition}
    $(a + b) + c = (a + c) + b$ for all $a, b, c \in \N$.
\end{corollary}
\begin{proof}
    See \myref{exercise:right-commutativity-of-addition} (later).
\end{proof}

\begin{exercise}[A Commutative Result]\label{exercise:right-commutativity-of-addition}
    Prove \myref{corollary:right-commutativity-of-addition}.\newline
    (\textit{Hint: you do not need induction.})
\end{exercise}

\subsection{Implications of Addition}
With these basic properties of addition defined, we can look at some consequences with regards to addition.

\begin{proposition}[Cancellation Property of Addition]\index{addition!cancellation property}\label{prop:addition-cancellation-property}
    Let $a, b, n \in \N$. If $a + n = b + n$ then $a = b$. Likewise if $n + a = n + b$ then $a = b$.
\end{proposition}
\begin{proof}
    We will only prove that if $a + n = b + n$ then $a = b$ since the other case is clearly taken care of by commutativity of addition (\myref{theorem:addition-commutative-naturals}). We will do this by inducting on $n$.

    When $n = 0$, the left-hand side is $a + 0 = b + 0$ which clearly simplifies to $a = b$ by \textbf{A1}. Thus the base case holds.

    Suppose $a + k = b + k$ means $a = b$ for some $k \in \N$. We will show that $a + \Successor{k} = b + \Successor{k}$ means $a = b$.

    We see that
    \begin{align*}
        &a + \Successor{k} = b + \Successor{k}\\
        \iff& \Successor{a + k} = \Successor{b + k} & (\text{by \textbf{A2}})\\
        \iff& a + k = b + k & (\text{by \myref{example:successor-is-injective}})\\
        \iff& a = b &(\text{induction hypothesis})
    \end{align*}
    so the case for $\Successor{k}$ is also true.
\end{proof}

\begin{proposition}[Addition that Equals Self]\label{prop:addition-that-equals-self}
    Let $a, b \in \N$. If $a + b = b$ then $a = 0$. Likewise if $a + b = a$ then $b = 0$.
\end{proposition}
\begin{proof}
    See \myref{exercise:addition-that-equals-self} (later).
\end{proof}

\begin{proposition}[Addition that Equals Zero]
    Let $a, b \in \N$. If $a + b = 0$ then $a = 0$ and $b = 0$.
\end{proposition}
\begin{proof}
    We only prove the case that if $a + b = 0$ then $a = 0$, since the other is easily implied by commutativity of addition (\myref{theorem:addition-commutative-naturals}).

    There are two cases to consider. The first is if $b = 0$. Then one clearly sees that the left-hand side is $a + 0$ which is $a$ by \textbf{A1}, and the right-hand side is 0. Thus $a = 0$ as required.

    The other case is that $b \neq 0$. So $b$ is a successor of some other natural number, say $d \in \N$. Thus we have $a + \Successor{d} = 0$, which by \textbf{A2} is the same as $\Successor{a + d} = 0$. So
    \[
        \Successor{\underbrace{a + d}_{\text{In } \N}} = 0
    \]
    which is a contradiction since 0 is not the successor of any natural number.

    Thus we have $a = 0$ (and $b = 0$).
\end{proof}

\begin{exercise}[Addition that Equals Self]\label{exercise:addition-that-equals-self}
    Prove \myref{prop:addition-that-equals-self}.
\end{exercise}

\section{Multiplication}
With addition defined, we can now turn our attention to defining the next most important operation: multiplication.

\subsection{Basic Definitions}
Like with addition, it is of no use to us to just say that multiplication is a binary operation on $\N$. We need to find properties that multiplication satisfy in order to build a meaningful definition for it. Just like with addition, we will focus our attention on the interaction of multiplication with 0 and the successor of a number.

What happens when we multiply a number by zero? That is easy -- the answer is just zero. But what happens when we multiply a number by the successor of another number? Well, by \myref{prop:successor-of-n}, we know that $\Successor{n} = n + 1$, and we know by algebra that $x(y + 1) = xy + x$. So we can adopt this property into our definition for multiplication.

\begin{definition}[Multiplication]
    The \term{multiplication operation}\index{multiplication} is the function $\times: \N^2 \to \N$ such that
    \begin{enumerate}[label=\textbf{M\arabic*.}]
        \item for all $n \in \N$ we have $n \times 0 = 0$; and
        \item for all $n, d \in \N$ we have $n \times \Successor{d} = (n \times d) + n$.
    \end{enumerate}
\end{definition}

Like with addition, these two conditions will be all we need to prove the most essential properties of multiplication.

For the ease of notation, we may choose to omit the ``$\times$'' when writing the multiplication of two algebraic symbols, i.e. $ab$ is the same as $a\times b$ for $a,b \in \N$. However, if it serves to improve readability, we will write the ``$\times$'' in between the symbols.

\subsection{Commutativity}
First, an easy warm-up property.

\begin{proposition}[Multiplication by One]\label{prop:multiplication-by-1-right}
    $n \times 1 = n$ for all $n \in \N$.
\end{proposition}
\begin{proof}
    One sees
    \begin{align*}
        n \times 1 &= n \times \Successor{0} & (\text{by definition of 1})\\
        &= n \times 0 + n & (\text{by \textbf{M2}})\\
        &= 0 + n & (\text{by \textbf{M1}})\\
        &= n & (\text{by \myref{lemma:sum-of-0-and-n}})
    \end{align*}
    so $n \times 1 = n$ as required.
\end{proof}

The next few results are analogous to those covered in the earlier section on addition. Again, note that \textbf{M1} works for $n \times 0$, not $0 \times n$, so we need this lemma.

\begin{lemma}[Product of 0 and $n$]\label{lemma:product-of-0-and-n}
    $0 \times n = 0$ for all $n \in \N$.
\end{lemma}

\begin{proof}
    See \myref{exercise:proof-of-commutativity} (later).
\end{proof}

\begin{lemma}[Product of $\Successor{d}$ and $n$]\label{lemma:product-of-successor-and-n}
    $\Successor{d} \times n = (d \times n) + n$ for all $n, d \in \N$.
\end{lemma}
\begin{proof}
    We consider induction on $n$.

    When $n = 0$, we have $\Successor{d} \times 0$ on the left-hand side, which easily simplifies to 0 by \textbf{M1}. The right-hand side, upon substituting $n = 0$, becomes $d \times 0 + 0$ which is $0 + 0$ by \textbf{M1} and becomes 0 upon using \textbf{A1}. Since the left-hand side and right-hand side both equal 0, thus the base case is proven.

    Suppose that $\Successor{d} \times k = (d \times k) + k$ for some $k \in \N$. We show that $\Successor{d} \times \Successor{k} = \left(d \times \Successor{k}\right) + \Successor{k}$.

    One sees that
    \begin{align*}
        &\Successor{d} \times \Successor{k}\\
        &= \left(\Successor{d} \times k\right) + \Successor{d} & (\text{by \textbf{M2}})\\
        &= \left((d \times k) + k\right) + \Successor{d} & (\text{induction hypothesis})\\
        &= (d \times k) + \left(k + \Successor{d}\right) & (\text{by associativity of addition})\\
        &= (d \times k) + \left(k + (d + 1)\right) & (\text{by \myref{prop:successor-of-n}})\\
        &= (d \times k) + \left((k + d) + 1\right) & (\text{by associativity of addition})\\
        &= (d \times k) + \left((k + 1) + d\right) & (\text{by \myref{corollary:right-commutativity-of-addition}})\\
        &= (d \times k) + \left(\Successor{k} + d\right) & (\text{by \myref{prop:successor-of-n}})\\
        &= (d \times k) + \left(d + \Successor{k}\right) & (\text{by commutativity of addition})\\
        &= \left((d \times k) + d\right) + \Successor{k} & (\text{by associativity of addition})\\
        &= \left(d \times \Successor{k}\right) + \Successor{k} & (\text{by \textbf{M2}})
    \end{align*}
    which proves the case for $\Successor{k}$.
\end{proof}

We are now ready to prove the commutativity of multiplication.

\begin{theorem}[Commutativity of Multiplication (Naturals)]\label{theorem:multiplication-commutative-naturals}
    $m \times n = n \times m$ for all $m, n \in \N$.
\end{theorem}
\begin{proof}
    See \myref{exercise:proof-of-commutativity} (later).
\end{proof}

\begin{exercise}[Proof of Commutativity]\label{exercise:proof-of-commutativity}
    \begin{partquestions}{\roman*}
        \item Prove \myref{lemma:product-of-0-and-n}.
        \item Prove \myref{theorem:multiplication-commutative-naturals}.
    \end{partquestions}
\end{exercise}

With the commutativity of multiplication proven, we can prove some intuitive results.

\begin{corollary}[Multiplication by One (on the Left)]\label{corollary:multiplication-by-1}
    $1 \times n = n$ for all $n \in \N$.
\end{corollary}
\begin{proof}
    One can use \myref{theorem:multiplication-commutative-naturals} to see that $1 \times n = n \times 1$, which clearly equals $n$ by \myref{prop:multiplication-by-1-right}.
\end{proof}

\subsection{Distributivity}
Recall that one of the core interactions of multiplication with addition is distributivity. For example, we can evaluate $3 \times (4 + 5)$ in two ways. The first is to first calculate $4 + 5 = 9$, and then calculate $3 \times 9 = 27$. The second is to `expand' the expression to become $3 \times 4 + 3 \times 5$, and then evaluating $3 \times 4 = 12$ and $3 \times 5 = 15$, and finally summing them both to get $12 + 15 = 27$.

This is summarised in the following theorem.

\begin{theorem}[Distributivity of $\times$ over $+$ (Naturals)]\index{multiplication!distributivity}\label{theorem:multiplication-distributivity-naturals}
    For all $a, b, c \in \N$ we have
    \begin{align*}
        a\times(b+c) &= (a\times b) + (a\times c) \text{ and}\\
        (a+b)\times c &= (a\times c) + (b\times c).
    \end{align*}
\end{theorem}
\begin{proof}
    We prove the first statement via induction on $a$.

    When $a = 0$, the left-hand side is $0\times(b+c) = 0$ by \myref{lemma:product-of-0-and-n}. The right-hand side is $0\times b + 0\times c = 0 + 0$ by \myref{lemma:product-of-0-and-n} again, which clearly equals 0 by \textbf{A1}. So the left-hand side equals the right-hand side, proving the base case.

    Suppose $k\times(b+c) = (k\times b) + (k\times c)$ for some $k \in \N$. We show that $\Successor{k}\times(b+c) = (\Successor{k}\times b) + (\Successor{k} \times c)$.

    Observe that
    \begin{align*}
        &\Successor{k}\times(b+c)\\
        &= (k \times (b+c)) + (b+c) & (\text{by \myref{lemma:product-of-successor-and-n}})\\
        &= ((k\times b) + (k\times c)) + (b+c) & (\text{induction hypothesis})\\
        &= ((k\times b) + b) + ((k\times c) + c) & (\text{by properties of addition})\\
        &= (\Successor{k}\times b) + (\Successor{k} \times c) & (\text{by \myref{lemma:product-of-successor-and-n}})
    \end{align*}
    which proves the case for $\Successor{k}$.

    The second statement is readily proven by using \myref{theorem:multiplication-commutative-naturals} on the first statement to get
    \[
        (b+c)\times a = (a\times b) + (a\times c)
    \]
    Then by `renaming' $b$ to $a$, $c$ to $b$, and $a$ to $c$, we will get that
    \[
        (a+b)\times c = (c\times a) + (c\times b).
    \]
    Using \myref{theorem:multiplication-commutative-naturals} on the two products on the right-hand side readily proves the second theorem.
\end{proof}

\subsection{Associativity}
With distributivity proven, we are ready to prove the associativity of multiplication.

\begin{theorem}[Associativity of Multiplication (Naturals)]\index{multiplication!associativity}\label{theorem:multiplication-associative-naturals}
    $(a \times b) \times c = a \times (b \times c)$ for all $a, b, c \in \N$.
\end{theorem}
\begin{proof}
    We induct on $c$.

    When $c = 0$, the left-hand side is $(a \times b) \times 0$ which is 0 by \textbf{M1}. The right-hand side is
    \begin{align*}
        a \times (b \times 0) &= a \times 0 & (\text{by \textbf{M1}})\\
        &= 0  & (\text{by \textbf{M1} again})
    \end{align*}
    so the left-hand side and the right-hand side are the same, proving the base case.

    Suppose that $(a \times b) \times k = a \times (b \times k)$ for some $k \in \N$. We will demonstrate that $(a \times b) \times \Successor{k} = a \times (b \times \Successor{k})$.

    One can see that
    \begin{align*}
        &(a \times b) \times \Successor{k}\\
        &= (a \times b) \times (k + 1) & (\text{by \myref{prop:successor-of-n}})\\
        &= ((a \times b) \times k) + ((a \times b) \times 1) & (\text{by \myref{theorem:multiplication-distributivity-naturals}})\\
        &= ((a \times b) \times k) + (a \times b) & (\text{by \myref{corollary:multiplication-by-1}})\\
        &= (a \times(b \times k)) + (a \times b) & (\text{induction hypothesis})\\
        &= a \times ((b \times k) + b) & (\text{by \myref{theorem:multiplication-distributivity-naturals}})\\
        &= a \times ((b \times k) + (b \times 1)) & (\text{by \myref{corollary:multiplication-by-1}})\\
        &= a \times (b \times (k + 1)) & (\text{by \myref{theorem:multiplication-distributivity-naturals}})\\
        &= a \times (b \times \Successor{k}) & (\text{by \myref{prop:successor-of-n}})
    \end{align*}
    which proves the case for $\Successor{k}$.
\end{proof}

\section{Exponentiation}
This last section will introduce exponentiation in the natural numbers. Just like how multiplication can be thought of as repeated addition, exponentiation can be thought of as repeated multiplication.

\subsection{Basic Definitions}
As before, we investigate the interactions of exponentiation with 0 and the successor of a number.

When we raise any non-zero number to the power of 0, what do we get? Before that, what does it mean to raise a number to the power of 0? Well, that means that we do not multiply anything at all. But what should this value be? Just like how multiplying by 1 does not change the product of a sequence of numbers, if we don't multiply by anything at all we should just get 1.

\begin{remark}[$0^0$]
    The elephant in the room is, of course, the value of $0^0$. Some authors define this to be 1, some say 0, and others say that this is undefined. To make our lives easier for proving the properties of exponentiation later, let us just say that $0^0 = 1$. We will see this proved later.
\end{remark}

Now what about if we raise any number to a successor of another number? Well, if that other number is $a$, then we know by \myref{prop:successor-of-n} that its successor is $a+1$. Logically this should mean that we multiply one more copy of the base number.

We can thus define exponentiation as follows.

\begin{definition}[Exponentiation]
    The \term{exponentiation operation}\index{exponentiation} is the function $\wedge: \N^2 \to \N$ such that
    \begin{enumerate}[label=\textbf{E\arabic*.}]
        \item for all $n \in \N$ we have $n \wedge 0 = 1$; and
        \item for all $n, d \in \N$ we have $n \wedge \Successor{d} = (n \wedge d) \times n$.
    \end{enumerate}
\end{definition}

Of course, we do not usually write ``$\wedge$'' for exponentiation; we just use a superscript. Thus $(2 \wedge 3) \wedge 4 = \left(2^3\right)^4$. However, if it serves to improve readability, we will write the ``$\wedge$''.

\begin{exercise}[Exponentiation is Unlike the Rest]
    Which of the following statement(s) are true?
    \begin{partquestions}{\alph*}
        \item For all $a, b \in \N$ we have $a \wedge b = b \wedge a$.
        \item For all $a, b, c \in \N$ we have $(a \wedge b) \wedge c = a \wedge (b \wedge c)$.
    \end{partquestions}
\end{exercise}

\subsection{Basic Properties}
Let us look at some basic properties of exponentiation.

\begin{proposition}[Zero to the Power of a Natural Number]
    \[
        0^n = \begin{cases}
            1 & \text{if } n = 0\\
            0 & \text{otherwise}
        \end{cases}
    \]
    for all $n \in \N$.
\end{proposition}
\begin{proof}
    The case when $n = 0$ is obvious by using \textbf{E1}. Otherwise, we know that $n$ is the successor of some other natural number, say $m$. Thus
    \begin{align*}
        0^n &= 0^\Successor{m}\\
        &= 0^m \times 0 & (\text{by \textbf{E2}})\\
        &= 0, & (\text{by \textbf{M1}})
    \end{align*}
    proving the second case.
\end{proof}

\begin{proposition}[Natural Number to the Power of One]\label{prop:power-of-1}
    $n^1 = n$ for all $n \in \N$.
\end{proposition}
\begin{proof}
    See \myref{exercise:power-of-1} (later).
\end{proof}

\begin{proposition}[One to the Power of a Natural Number]
    $1^n = 1$ for all $n \in \N$.
\end{proposition}
\begin{proof}
    We induct on $n$.

    The base case of $n = 0$ is easily proven by using \textbf{E1}.

    Suppose $1^k = 1$ for some $k \in \N$. We show $1^\Successor{k} = 1$.

    Note
    \begin{align*}
        1^\Successor{k} &= (1^k) \times 1 & (\text{by \textbf{E2}})\\
        &= 1 \times 1 & (\text{induction hypothesis})\\
        &= 1 & (\text{by \myref{corollary:multiplication-by-1}})
    \end{align*}
    which proves the case for $\Successor{k}$.
\end{proof}

\begin{proposition}[Square]
    $n^2 = n \times n$ for all $n \in \N$.
\end{proposition}
\begin{proof}
    We see that
    \begin{align*}
        n^2 &= n^\Successor{1}\\
        &= n^1 \times n & (\text{by \textbf{E2}})\\
        &= n \times n & (\text{by \myref{prop:power-of-1}})
    \end{align*}
    which proves the proposition.
\end{proof}

\begin{exercise}[Power of One]\label{exercise:power-of-1}
    Prove \myref{prop:power-of-1}.
\end{exercise}

\subsection{Laws of Exponents}
We end this chapter by looking at the laws of exponents.

\begin{theorem}[Product With Same Base]\label{theorem:exponents-product-with-same-base}
    $a^m \times a^n = a^{m+n}$ for all $a, m, n \in \N$.
\end{theorem}
\begin{proof}
    We induct on $n$.

    For the base case $n = 0$, we see that
    \begin{align*}
        a^m \times a^0 &= a^m \times 1 & (\text{by \textbf{E1}})\\
        &= a^m & (\text{by \myref{prop:multiplication-by-1-right}})\\
        &= a^{m+0} & (\text{by \textbf{A1}})
    \end{align*}
    so the base case is true.

    Suppose $a^m \times a^k = a^{m+k}$ for some $k \in \N$. We will demonstrate that $a^m \times a^\Successor{k} = a^{m+\Successor{k}}$.

    One sees that
    \begin{align*}
        a^m \times a^\Successor{k} &= a^m \times \left(a^k \times a\right) & (\text{by \textbf{E2}})\\
        &= \left(a^m \times a^k\right) \times a & (\text{by \myref{theorem:multiplication-associative-naturals}})\\
        &= a^{m+k} \times a & (\text{induction hypothesis})\\
        &= a^{\Successor{m+k}} & (\text{by \textbf{E1}})\\
        &= a^{m+\Successor{k}} & (\text{by \textbf{A2}})
    \end{align*}
    which proves the case for $\Successor{k}$.
\end{proof}

\begin{theorem}[Product to a Power]\label{theorem:exponents-product-to-a-power}
    $a^n \times b^n = (a\times b)^n$ for all $a, b, n \in \N$.
\end{theorem}
\begin{proof}
    See \myref{exercise:exponents-product-to-a-power} (later).
\end{proof}

\begin{theorem}[Power Raised to a Power]\label{theorem:exponents-power-raised-to-a-power}
    $\left(a^m\right)^n = a^{m\times n}$ for all $a, m, n \in \N$.
\end{theorem}
\begin{proof}
    We induct on $n$.

    For the base case $n = 0$, one sees clearly that
    \begin{align*}
        \left(a^m\right)^0 &= 1 & (\text{by \textbf{E1}})\\
        &= a^0 & (\text{by \textbf{E1} again})\\
        &= a^{m\times 0} & (\text{by \textbf{M1}})
    \end{align*}
    which proves the base case.

    Assume $\left(a^m\right)^k = a^{m\times k}$ for some $k \in \N$; we are to show that $\left(a^m\right)^\Successor{k} = a^{m\times \Successor{k}}$.

    We observe that
    \begin{align*}
        \left(a^m\right)^\Successor{k} &= \left(a^m\right)^k \times a^m & (\text{by \textbf{E2}})\\
        &= a^{m\times k} \times a^m & (\text{induction hypothesis})\\
        &= a^{m\times k + m} & (\text{by \myref{theorem:exponents-product-with-same-base}})\\
        &= a^{m \times \Successor{k}} & (\text{by \textbf{M2}})
    \end{align*}
    which proves the case for $\Successor{k}$.
\end{proof}

\begin{exercise}[Product to a Power]\label{exercise:exponents-product-to-a-power}
    Prove \myref{theorem:exponents-product-to-a-power}.
\end{exercise}
