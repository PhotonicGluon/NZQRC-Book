\Chapter{Counting and Cardinality}
\Lettrine[loversize=0.1,nindent=2pt]{Ironically}, it is often the case that rigorously defining something intuitive turns out to be exceedingly tricky. Such is the case of counting. Counting the number of things in a collection seems obvious, but creating a watertight protocol for counting is more challenging than it appears at first glance.

\section{The Problem With `Intuitive' Counting}
One would be hard-pressed to disagree that counting is such an obvious and trivial task that it is not worth dedicating an entire chapter to it. The very idea of saying how many things exist is, to us, deeply ingrained in our biology. Why do we need to define counting?

The core issue with counting is ensuring everyone agrees on how many items are there. Surely this task is trivial! Simply tally how many things there are! How hard can it be to make everyone agree on the number of items?

In the spirit of Socratic dialogue, let us examine two characters attempting to agree on how many shapes were drawn on a field.

Of course, this is a contrived example, but it is important to ask where it went wrong. The two main issues faced above were that either
\begin{itemize}
    \item not all the shapes were counted; or
    \item a shape was counted more than once.
\end{itemize}
With this in mind, how do determine how many elements exist in a set?

\section{An Introduction to Cardinality}
\begin{definition}[Cardinality]\label{definition:cardinality}
    \term{Cardinality}\index{cardinality}\index{set!cardinality} describes a relationship between sets which compares their relative size. The cardinality of a set $A$ is denoted $|A|$.
\end{definition}

It turns out that the cardinality of a finite set is the number of elements inside the set. Of course, defining the notion of cardinality only for finite sets defeats the purpose of defining counting -- how do we know how many elements are inside the set in the first place? To that end, let us \textbf{not} define cardinality of a set directly; instead, let us define the relationships between cardinalities, an approach adopted by the originator of set theory, Georg Ferdinand Cantor, around 1880.

\subsection{Bijections and Cardinality}
\begin{definition}[Equal Cardinality]\index{cardinality!equality}
    Let $A$ and $B$ be sets. Then $A$ and $B$ have equal cardinality (denoted $|A| = |B|$) if and only if there exists a bijection $f: A \to B$. Such sets are called \term{equinumerous}\index{equinumerous}\index{cardinality!equinumerous}.
\end{definition}

This should be intuitive for finite sets -- if we can pair the elements of two sets up exactly, they should have the same number of elements (which is analogous to their cardinalities).

\begin{example}[Equinumerous Sets]
    Let $A = \{a,b,c,d\}$ and $B = \{w,x,y,z\}$. We can define a bijection $f: A \to B$ where
    \[
        f = \{(a, w), (b, x), (c, y), (d, z)\}.
    \]
    So $|A| = |B|$, i.e. $A$ and $B$ are equinumerous.
    \begin{figure}[H]
        \centering
        \includegraphics[height=3cm]{images/part-1/counting/equinumerous-sets_f.png}
        \caption{Arrow Diagram of the Bijection $f$}
    \end{figure}
    Of course, there are other possible bijections. For example, the function $g: A \to B$ where
    \[
        g = \{(a, z), (b, x), (c, w), (d, y)\}
    \]
    is also a bijection.
    \begin{figure}[H]
        \centering
        \includegraphics[height=3cm]{images/part-1/counting/equinumerous-sets_g.png}
        \caption{Arrow Diagram of the Bijection $g$}
    \end{figure}
    The key thing that we need to show is that there exists at least one bijection. As long as we can find one such bijection, we can conclude that two sets are equinumerous.
\end{example}

This way of defining equal cardinality addresses the two issues that we noted when trying to count the shapes earlier. Every element must be accounted for, and every element must be counted at most once.

We note one important equivalence of cardinalities here.

\begin{proposition}[Cardinality of Image of Injection]\label{proposition:cardinality-of-image-of-injection}
    Let $A$ and $B$ be sets and let $f: A \to B$ be an injective function. Then $|A| = |f(A)|$, where
    \[
        f(A) = \{f(a) \vert a \in A\}.
    \]
\end{proposition}
\begin{proof}
    Let $\bar{f}: A \to f(A)$ where $\bar{f}(a) = f(a)$. We show that $\bar{f}$ is a bijection.
    \begin{itemize}
        \item \textbf{Injective}: Suppose $\bar{f}(a_1) = \bar{f}(a_2)$ for some $a_1, a_2 \in A$. Thus $f(a_1) = f(a_2)$ by definition of $\bar{f}$. Since $f$ is assumed to be injective, thus $a_1 = a_2$, which means $\bar{f}$ is injective.
        \item \textbf{Surjective}: Suppose $y \in f(A)$. Note $y = f(a)$ for some $a \in A$ by definition of $f(A)$. Thus $a$ is the preimage of $y$ because $\bar{f}(a) = f(a) = y$. Hence $\bar{f}$ is surjective.
    \end{itemize}
    Therefore $\bar{f}$ is a bijection, which means $|A| = |f(A)|$.
\end{proof}

\subsection{Injections/Surjections and Cardinality}
What happens when we try and measure the cardinality of two sets that do not have a bijection between them?

\begin{example}[Non-Equinumerous Sets]
    Consider the sets $A = \{a,b,c,d\}$ and $B = \{v,w,x,y,z\}$. No matter how hard we try, we cannot find a bijection between these two sets. There seems to always be at least one element left unmapped from $A$ to $B$.
    \begin{figure}[H]
        \centering
        \includegraphics[height=3cm]{images/part-1/counting/non-equinumerous-sets.png}
        \caption{Arrow Diagram by Some Function $f$}
    \end{figure}
\end{example}

Okay, let us try weakening the condition for the function $f$ in \myref{definition:cardinality}. What happens if we don't require $f$ to be surjective (i.e., $f$ is injective only). Of course, if $f$ is surjective we can still conclude that $|A| = |B|$. What happens when we can only find injective functions from $A$ to $B$? Just like the previous example, we can see that the set $B$ is `larger' than the set $A$. This motivates the definition of smaller cardinality.

\begin{definition}[Smaller (or Equal) Cardinality]\index{cardinality!smaller}\label{definition:smaller-or-equal-cardinality}
    Let $A$ and $B$ be sets. Then $A$ has a cardinality smaller than or equal to $B$ (denoted $|A| \leq |B|$) if and only if there exists an injection $f: A \to B$.
    
    We say that $A$ has a cardinality smaller than $B$ (denoted $|A| < |B|$) if and only if $|A| \leq |B|$ and there does not exist a bijection from $A$ to $B$.
\end{definition}

What if a surjection from $A$ to $B$ exists? What can we conclude?

\begin{definition}[Larger (or Equal) Cardinality]\index{cardinality!larger}\label{definition:larger-or-equal-cardinality}
    Let $A$ and $B$ be sets. Then $A$ has a cardinality larger than or equal to $B$ (denoted $|A| \geq |B|$) if and only if there exists a surjection $f: A \to B$.
    
    We say that $A$ has a cardinality larger than $B$ (denoted $|A| > |B|$) if and only if $|A| \geq |B|$ and there does not exist a bijection from $A$ to $B$.
\end{definition}

Wait a minute, does \myref{definition:smaller-or-equal-cardinality} agree with \myref{definition:larger-or-equal-cardinality}? That is, if we have two sets $A$ and $B$, if $|A| \leq |B|$, do we also have $|B| \geq |A|$? It turns out that we do.

\begin{theorem}[Agreement of \myref{definition:smaller-or-equal-cardinality} and \myref{definition:larger-or-equal-cardinality}]\label{theorem:agreement-of-cardinality-definitions}
    Let $A$ and $B$ be sets. Then $|A| \geq |B|$ if and only if there exists an injection from $B$ to $A$.
\end{theorem}
\begin{proof}
    We only prove the forward direction here and leave the reverse direction for \myref{exercise:agreement-of-cardinality-definitions} (later).

    Suppose $|A| \geq |B|$. By \myref{definition:larger-or-equal-cardinality} this means that there exists a surjection from $A$ to $B$, say $f$. Our goal is to construct an injection, say $g$, from $B$ to $A$. 
    
    First, because $f$ is surjective, which means that for any $b \in B$ there exists at least one $a \in A$ such that $f(a) = b$. So define a function $g: B \to A$ such that $g(b) = a$ for one specific $a$ where $f(a) = b$ for all $b \in B$. Note that we specifically choose only one $a$ per $b$ for the definition of $g$, which makes it a valid function. We are able to choose this $a$ due to the axiom of choice (\myref{axiom:choice}).

    Now we need to prove that $g$ is injective. Suppose $g(b_1) = g(b_2)$ for some $b_1, b_2 \in B$. Let $g(b_1) = a$ (which also means $g(b_2) = a$ too). By definition of $g$, we must have $f(a) = b_1$ and $f(a) = b_2$, which means $b_1 = b_2$. Hence $g$ is injective, completing the forward direction.
\end{proof}

\begin{exercise}[Complete the Proof!]\label{exercise:agreement-of-cardinality-definitions}
    Complete the proof of \myref{theorem:agreement-of-cardinality-definitions}.
\end{exercise}

\subsection{Cantor-Schr\"oder-Bernstein}
The symbols ``$\leq$'' and ``$\geq$'' used for comparing cardinalities hint at an interesting idea: if $|A| \leq |B|$ and $|B| \leq |A|$, is $|A| = |B|$? In fact, this is a corollary of the Cantor-Schr\"oder-Bernstein Theorem. The proof of this theorem is complex, so we will leave it to the end of this chapter.

\begin{theorem}[Cantor-Schr\"oder-Bernstein]\label{theorem:cantor-schroder-bernstein}
    Let $A$ and $B$ be sets. If there are injections $f: A \to B$ and $g: B \to A$, then there exists a bijection $h: A \to B$.
\end{theorem}

\begin{corollary}\label{corollary:cantor-schroder-bernstein-corollary}
    Let $A$ and $B$ be sets. If $|A| \leq |B|$ and $|B| \leq |A|$ then $|A| = |B|$.
\end{corollary}
\begin{proof}
    By definition we know that $|A| \leq |B|$ means that there exists an injection from $A$ to $B$ and $|B| \leq |A|$ means that there exists an injection from $B$ to $A$. Thus \myref{theorem:cantor-schroder-bernstein} tells us that there is a bijection from $A$ to $B$, which hence means $|A| = |B|$.
\end{proof}

\begin{example}
    \setlength{\parindent}{1.5em}
    Let $A$ be a set and $B$ be a subset of $A$. We show that if there is an injection from $A$ to $B$ then $|A| = |B|$.
    \begin{proof}
        Our goal is to find injections from $A$ to $B$ and from $B$ to $A$ and then use Cantor-Schr\"oder-Bernstein (\myref{theorem:cantor-schroder-bernstein}) to finish the proof.

        The injection $f: A \to B$ is assumed to exist by our antecedent. The injection $g: B \to A$ can be found simply by defining $f(x) = x$ for all $x \in B$. One clearly sees that if $g(x_1) = g(x_2)$ then $x_1 = x_2$ for all $x_1, x_2 \in B$.

        Thus Cantor-Schr\"oder-Bernstein tells us that there exists a bijection from $A$ to $B$, which means $|A| = |B|$.
    \end{proof}
\end{example}

There are more interesting examples of using the Cantor-Schr\"oder-Bernstein theorem, but we will cover them when the time comes.

\section{Finite Counting}
With an introduction of cardinality out of the way, we can finally define a way to count the number of items in a finite set.

\begin{example}[A Set of 5]
    Consider the set $A = \{a, b, c, d, e\}$. One clearly sees that the set $B = \{0, 1, 2, 3, 4\}$ is equinumerous with the set $A$ by using the bijection
    \[
        f = \{(a, 0), (b, 1), (c, 2), (d, 3), (e, 4)\}.
    \]

    But notice that the set $B$ is exactly the counter set for 5. So, in a sense, we can write
    \[
        |A| = |5|.
    \]
\end{example}

\begin{example}[A Set of 7]
    Consider the set $A = \{73, 75, 93, 103, 848, 3742, 3999\}$. One clearly sees that the set $B = \{0, 1, 2, 3, 4, 5, 6\}$ is equinumerous with the set $A$ by using the bijection
    \[
        f = \{(73, 0), (75, 1), (93, 2), (103, 3), (848, 4), (3742, 5), (3999, 6)\}.
    \]

    But notice that the set $B$ is exactly the counter set for 7. So, in a sense, we can write
    \[
        |A| = |7|.
    \]
\end{example}

\begin{example}[A Set of 0]
    Consider the empty set $\emptyset$. This is exactly the counter set for 0, and thus
    \[
        |\emptyset| = |0|.
    \]
\end{example}

It is surely inconvenient (and unintuitive) to use the cardinality of the counter set of a natural number. Thus, we may abuse the notation for cardinality slightly.

\begin{definition}[A Slight Abuse of Cardinality of Counter Sets]
    Define $|n| = n$ for all $n \in \N$. That is, the cardinality of the counter set of $n$ is exactly $n$.
\end{definition}

With this definition we can write the cardinality of finite sets more intuitively.

\begin{example}[Cardinalities of Finite Sets]
    \begin{itemize}[leftmargin=*]
        \item For $A = \{a, b, c, d, e\}$, since $|A| = |5|$, we can write $|A| = 5$. This is read as ``the cardinality of $A$ is 5''.
        \item For $A = \{73, 75, 93, 103, 848, 3742, 3999\}$ we can write $|A| = 7$, which is read ``the cardinality of $A$ is 7''.
        \item For the empty set we can write $|\emptyset| = 0$. This can be read as ``the empty set has cardinality 0''.
    \end{itemize}
\end{example}

\begin{exercise}[Finite Cardinalities]
    \begin{partquestions}{\alph*}
        \item What is the cardinality of the counter set of 7125?
        \item What is $|373267|$?
        \item Write down a set of cardinality 1.
        \item What is the cardinality of $13 \cup 14$?\newline
        (\textit{Hint: think of them as counter sets.})
    \end{partquestions}
\end{exercise}

We have an interesting result regarding maps between finite sets with the same cardinality.

\begin{theorem}[Map Between Finite Sets of Equal Cardinality]\label{theorem:map-between-finite-sets-of-equal-cardinality}
    Let $A$ and $B$ be finite sets such that $|A| = |B|$. Suppose $f: A \to B$ is a function. Then $f$ is a bijection if and only if $f$ is an injection.
\end{theorem}
\begin{proof}
    For the forward direction, if $f$ is a bijection then $f$ must be injective by definition of bijections.
    
    For the reverse direction, suppose $f$ is an injection. By \myref{proposition:cardinality-of-image-of-injection} we know that $|A| = |f(A)|$ where
    \[
        f(A) = \{f(a) \vert a \in A\}.
    \]
    As $|A| = |B|$, we have $|f(A)| = |B|$. Note that $f(A) \subseteq B$. Thus $f(A)$ is a subset of $B$ with the same number of elements as $B$, which means $f(A) = B$. But clearly this means that any element in $B$ can be expressed in the form $f(a)$ where $a \in A$, and thus under $f$ any $b = f(a)$ has a preimage of $a$. Hence $f$ is also surjective, which means $f$ is a bijection.
\end{proof}

\section{Infinite Sets and Infinite Counting}
We have an intuition of what a finite set is -- there is a limit to the number of items in the set. With our language of cardinality we can formally state this, using the definition found in \cite[p.~262]{boolos_1998}.

\begin{definition}[Finite Set]
    A set $S$ is \term{finite}\index{finite}\index{set!finite} if and only if there exists a bijection $f: S \to n$ for some $n \in \N$ (here $n$ represents the counter set of $n$). In other words, $S$ is finite if and only if $|S| = n$ for some $n \in \N$.
\end{definition}

\begin{example}[Examples of Finite Sets]
    \begin{itemize}[leftmargin=*]
        \item The set $\{2, 3, 5\}$ is finite since $|\{2, 3, 5\}| = 3$.
        \item The set $\{a, b, 1, 2, !\}$ is finite since $|\{a, b, 1, 2, !\}| = 5$.
        \item The empty set is finite since $|\emptyset| = 0$.
    \end{itemize}
\end{example}

Infinite sets can thus be defined as follows.

\begin{definition}[Infinite Set]
    A set $S$ is \term{infinite}\index{infinite}\index{set!infinite} if and only if $S$ is not finite. In other words, there does not exist a bijection $f: S \to n$ for all $n \in \N$.
\end{definition}

We have already seen some examples of infinite sets.

\begin{example}[$\N$]
    \setlength{\parindent}{1.5em}
    Based on the definition above, it should be the case that $\N$ given by the axiom of infinity (\myref{axiom:infinity}) is an infinite set. In fact, it is.
    \begin{proof}
        We consider a proof by contradiction. Suppose $\N$ is finite. Consider the successor function $S: \N \to \N$ where $S(n) = n \cup \{n\}$ for all $n \in \N$. We show that $S$ is injective.

        Suppose $n_1, n_2 \in \N$ such that $S(n_1) = S(n_2)$. Thus $n_1 \cup \{n_1\} = n_2 \cup \{n_2\}$. This means that
        \[
            \{0, 1, \dots, n_1\} = \{0, 1, \dots, n_2\}
        \]
        which thus means that $n_1 = n_2$. Hence $S$ is injective.
        
        As $\N$ is (assumed to be) finite, we know by \myref{theorem:map-between-finite-sets-of-equal-cardinality} this means that $S$ is bijective, which means $S$ is surjective. But one sees that 0 has no preimage under $S$, which thus means $S$ cannot be surjective. This is a contradiction. Hence $\N$ is not finite.
    \end{proof}
\end{example}

\begin{example}[$\Successor{\N}$]
    \setlength{\parindent}{1.5em}
    We show that $\Successor{\N} = \N \cup \{\N\}$ is also not a finite set by showing that $|\Successor{\N}| = |\N|$.
    \begin{proof}
        First consider the function $S: \N \to \Successor{\N}$ where $S(n) = n \cup \{n\}$ for all $n \in \N$. Using a similar argument as the previous example we can show that $S$ is injective.

        Now consider the function $S': \Successor{\N} \to \N$ where $S'(n) = n \cup \{n\}$ for all $n \in \Successor{\N}$. Again using a similar argument we can show that $S'$ is injective.

        So Cantor-Schr\"oder-Bernstein (\myref{theorem:cantor-schroder-bernstein}) tells us that there is a bijection from $\N$ to $\Successor{\N}$, i.e. $|\N| = |\Successor{\N}|$.
    \end{proof}
\end{example}

But this is weird. Clearly $\Successor{\N}$ contains one more element than $\N$ (which is $\N$), and yet they have the same cardinality! This is the trap when we think of cardinalities as `sizes' of sets -- an infinite set with `more' elements can have the same `size' as an infinite set with `less' elements. Thus, cardinalities for infinite sets should be considered its own beast, and not the same as the `sizes' for finite sets.

\section{Axiom of Power Set}
To create sets with a larger cardinality than $\N$, we need the power set -- the set of all subsets of a set. This set is explicitly instantiated for all sets in \ZFC~via the axiom of power set, the last axiom in \ZFC.

\begin{axiom}[Power Set]\label{axiom:power-set}\index{axiom!power set}\index{Zermelo-Frankel Set Theory!power set}
    \[
        \forall A \exists P \forall S (S \in P \iff \forall x (x \in S \implies x \in A))
    \]
\end{axiom}

In other words, for any set $A$ there is a set $P$ (the power set of $A$) such that for all sets $S$ in $P$, any element in $S$ is also in $A$. This clearly must mean that $S$ is a subset of $A$ and thus $P$, being the collection of all such subsets, is the power set $\Power{A}$.

\section{Cantor's Theorem and Larger Infinities}
So far, all the examples of infinite sets that we have seen so far seem to be of the same cardinality. For example, the set of natural numbers $\N$ has the same cardinality as $\Successor{\N}$. So is it that all infinite sets have the same cardinality? No. This surprising result is called Cantor's Theorem, and it involves the power set.

\begin{theorem}[Cantor]\index{Cantor's Theorem}\label{theorem:cantor}
    Let $A$ be a set. Then any function $f: A \to \Power{A}$ is not surjective. Consequently $|A| < |\Power{A}|$ for any set $A$.
\end{theorem}

Notice that this theorem does not just apply to finite sets -- this works for all sets, including infinite sets.

\begin{proof}
    Let $f: A \to \Power{A}$ be a function. Seeking a contradiction, suppose $f$ is surjective.
    
    Note that the set
    \[
        B = \{x \in A \vert x \notin f(x)\}
    \]
    exists by the axiom schema of specification (\myref{axiom:schema-of-specification}). Since $B \subseteq A$, thus $B \in \Power{A}$. As $f$ is (assumed to be) surjective, there must be a $\xi \in A$ such that $f(\xi) = B$.

    Let us determine whether $\xi$ is in $B$ or not.
    \begin{itemize}
        \item Suppose $\xi \in B$. Then, by definition of $B$, we know $\xi \notin f(\xi)$. But $f(\xi) = B$, which means $\xi \notin B$, a clear contradiction to the assumption that $\xi \in B$.
        \item However, if instead $\xi \notin B$, we see $\xi \notin f(\xi)$ since $B = f(\xi)$. But this must mean that $\xi \in B$ by definition of $B$, another contradiction.
    \end{itemize}
    So, in either case, we have a contradiction. What did we contradict? We contradicted the assumption that $f$ is surjective. Thus there is no surjective mapping from $A$ to $\Power{A}$, and hence no bijection from $A$ to $\Power{A}$.

    To prove that $|A| < |\Power{A}|$ we simply need to find an injection from $A$ to $\Power{A}$. This is left for \myref{exercise:cantor-last-part} (later).
\end{proof}

This surprising result uses the set $B$, sometimes called the \term{Cantor diagonal set of $f$}\index{Cantor diagonal set} (see \cite[Theorem 1210, p.~362]{dasgupta_2014}). We will see the use of the set later in this book.

\begin{exercise}[The Last Part of Cantor's Theorem]\label{exercise:cantor-last-part}
    Find an injection from $A$ to $\Power{A}$ for any set $A$.
\end{exercise}

In light of \myref{theorem:cantor}, we can start defining larger infinities. The `smallest' infinity is the cardinality of the real numbers, which is implied by the definition of infinite sets. We give notation for the cardinality of infinite sets.

\begin{definition}[Beth Numbers]\index{beth number}
    Define $\beth_0$ (read ``beth zero''\index{beth number!beth zero} or ``beth null''\index{beth number!beth null}) to be the cardinality of $\N$, i.e. $\beth_0 = |\N|$. Subsequently (assuming addition of natural numbers is defined), for any $n \in \N$, define
    \[
        \beth_{n+1} = |\Power{A}|
    \]
    where $|A| = \beth_n$.
\end{definition}

With Cantor's theorem (\myref{theorem:cantor}) we know that
\[
    \beth_0 < \beth_1 < \beth_2 < \dots < \beth_n < \dots
\]

\begin{example}[The First Few Beth Numbers]
    \begin{itemize}[leftmargin=*]
        \item $\beth_0 = |\N|$.
        \item $\beth_1 = |\Power{\N}|$.
        \item $\beth_2 = |\Power{\Power{\N}}|$.
        \item $\beth_3 = |\Power{\Power{\Power{\N}}}|$.
    \end{itemize}
\end{example}

The more common notation used for denoting the cardinality of an infinite set are the aleph numbers.

\begin{definition}[Aleph Numbers]\index{aleph number}
    Define $\aleph_0$ (read as ``aleph zero``\index{aleph number!aleph zero} or ``aleph null''\index{aleph number!aleph null}) to be $\beth_0$. Subsequently (assuming addition of natural numbers is defined), for any $n \in \N$, define $\aleph_{n+1}$ as the next cardinality such that $\aleph_n < \aleph_{n+1}$ and there does not exist a cardinality $\kappa$ such that $\aleph_n < \kappa < \aleph_{n+1}$.
\end{definition}

Unfortunately, determining the exact `form' of $\aleph_1$ is tricky. A well known question in mathematics is the \term{Continuum hypothesis}\index{Continuum Hypothesis}, which, in essence, asks whether
\[
    \aleph_1 = \beth_1.
\]
The surprising thing about this question is that \textbf{this is not decidable using \ZFC} -- we can neither prove nor disprove this statement within \ZFC. To decide on the truth or falsity of this statement requires us to create a new axiom, which is not needed for this book. We shall just leave this as a mathematical curiosity.
