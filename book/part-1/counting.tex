\Chapter{Counting and Cardinality}
\Lettrine[loversize=0.1,nindent=2pt]{Ironically}, it is often the case that rigorously defining something intuitive turns out to be exceedingly tricky. Such is the case of counting. Counting the number of things in a collection seems obvious, but creating a watertight protocol for counting is more challenging than it appears at first glance.

\section{The Problem With `Intuitive' Counting}
One would be hard-pressed to disagree that counting is such an obvious and trivial task that it is not worth dedicating an entire chapter to it. The very idea of saying how many things exist is, to us, deeply ingrained in our biology. Why do we need to define counting?

The core issue with counting is ensuring everyone agrees on how many items are there. Surely this task is trivial! Simply tally how many things there are! How hard can it be to make everyone agree on the number of items?

In the spirit of Socratic dialogue, let us examine two characters attempting to agree on how many shapes were drawn on a field.

\begin{dialogue}{Archilles}{Tortoise}[1.5em][1.5em]

Of course, this is a contrived example, but it is important to ask where it went wrong. The two main issues faced above were that either
\begin{itemize}
    \item not all the shapes were counted; or
    \item a shape was counted more than once.
\end{itemize}
With this in mind, how do determine how many elements exist in a set?

\section{An Introduction to Cardinality}
\begin{definition}[Cardinality]\label{definition:cardinality}
    \term{Cardinality}\index{cardinality}\index{set!cardinality} describes a relationship between sets which compares their relative size. The cardinality of a set $A$ is denoted $|A|$.
\end{definition}

It turns out that the cardinality of a finite set is the number of elements inside the set. Of course, defining the notion of cardinality only for finite sets defeats the purpose of defining counting -- how do we know how many elements are inside the set in the first place? To that end, let us \textbf{not} define cardinality of a set directly; instead, let us define the relationships between cardinalities, an approach adopted by the originator of set theory, Georg Ferdinand Cantor, around 1880.

\subsection{Bijections and Cardinality}
\begin{definition}[Equal Cardinality]\index{cardinality!equality}
    Let $A$ and $B$ be sets. Then $A$ and $B$ have equal cardinality (denoted $|A| = |B|$) if and only if there exists a bijection $f: A \to B$. Such sets are called \term{equinumerous}\index{equinumerous}\index{cardinality!equinumerous}.
\end{definition}

This should be intuitive for finite sets -- if we can pair the elements of two sets up exactly, they should have the same number of elements (which is analogous to their cardinalities).

\begin{example}[Equinumerous Sets]
    Let $A = \{a,b,c,d\}$ and $B = \{w,x,y,z\}$. We can define a bijection $f: A \to B$ where
    \[
        f = \{(a, w), (b, x), (c, y), (d, z)\}.
    \]
    So $|A| = |B|$, i.e. $A$ and $B$ are equinumerous.
    \begin{figure}[H]
        \centering
        \includegraphics[height=3cm]{images/part-1/counting/equinumerous-sets_f.png}
        \caption{Arrow Diagram of the Bijection $f$}
    \end{figure}
    Of course, there are other possible bijections. For example, the function $g: A \to B$ where
    \[
        g = \{(a, z), (b, x), (c, w), (d, y)\}
    \]
    is also a bijection.
    \begin{figure}[H]
        \centering
        \includegraphics[height=3cm]{images/part-1/counting/equinumerous-sets_g.png}
        \caption{Arrow Diagram of the Bijection $g$}
    \end{figure}
    The key thing that we need to show is that there exists at least one bijection. As long as we can find one such bijection, we can conclude that two sets are equinumerous.
\end{example}

This way of defining equal cardinality addresses the two issues that we noted when trying to count the shapes earlier. Every element must be accounted for, and every element must be counted at most once.

\subsection{Injections/Surjections and Cardinality}
What happens when we try and measure the cardinality of two sets that do not have a bijection between them?

\begin{example}[Non-Equinumerous Sets]
    Consider the sets $A = \{a,b,c,d\}$ and $B = \{v,w,x,y,z\}$. No matter how hard we try, we cannot find a bijection between these two sets. There seems to always be at least one element left unmapped from $A$ to $B$.
    \begin{figure}[H]
        \centering
        \includegraphics[height=3cm]{images/part-1/counting/non-equinumerous-sets.png}
        \caption{Arrow Diagram by Some Function $f$}
    \end{figure}
\end{example}

Okay, let us try weakening the condition for the function $f$ in \myref{definition:cardinality}. What happens if we don't require $f$ to be surjective (i.e., $f$ is injective only). Of course, if $f$ is surjective we can still conclude that $|A| = |B|$. What happens when we can only find injective functions from $A$ to $B$? Just like the previous example, we can see that the set $B$ is `larger' than the set $A$. This motivates the definition of smaller cardinality.

\begin{definition}[Smaller (or Equal) Cardinality]\index{cardinality!smaller}\label{definition:smaller-or-equal-cardinality}
    Let $A$ and $B$ be sets. Then $A$ has a cardinality smaller than or equal to $B$ (denoted $|A| \leq |B|$) if and only if there exists an injection $f: A \to B$.
    
    We say that $A$ has a cardinality smaller than $B$ (denoted $|A| < |B|$) if and only if $|A| \leq |B|$ and there does not exist a bijection from $A$ to $B$.
\end{definition}

What if a surjection from $A$ to $B$ exists? What can we conclude?

\begin{definition}[larger (or Equal) Cardinality]\index{cardinality!larger}\label{definition:larger-or-equal-cardinality}
    Let $A$ and $B$ be sets. Then $A$ has a cardinality larger than or equal to $B$ (denoted $|A| \geq |B|$) if and only if there exists a surjection $f: A \to B$.
    
    We say that $A$ has a cardinality larger than $B$ (denoted $|A| > |B|$) if and only if $|A| \geq |B|$ and there does not exist a bijection from $A$ to $B$.
\end{definition}

Wait a minute, does \myref{definition:smaller-or-equal-cardinality} agree with \myref{definition:larger-or-equal-cardinality}? That is, if we have two sets $A$ and $B$, if $|A| \leq |B|$, do we also have $|B| \geq |A|$? It turns out that we do.

\begin{theorem}[Agreement of \myref{definition:smaller-or-equal-cardinality} and \myref{definition:larger-or-equal-cardinality}]\label{theorem:agreement-of-cardinality-definitions}
    Let $A$ and $B$ be sets. Then $|A| \geq |B|$ if and only if there exists an injection from $B$ to $A$.
\end{theorem}
\begin{proof}
    We only prove the forward direction here and leave the reverse direction for \myref{exercise:agreement-of-cardinality-definitions} (later).

    Suppose $|A| \geq |B|$. By \myref{definition:larger-or-equal-cardinality} this means that there exists a surjection from $A$ to $B$, say $f$. Our goal is to construct an injection, say $g$, from $B$ to $A$. 
    
    First, because $f$ is surjective, which means that for any $b \in B$ there exists at least one $a \in A$ such that $f(a) = b$. So define a function $g: B \to A$ such that $g(b) = a$ for one specific $a$ where $f(a) = b$ for all $b \in B$. Note that we specifically choose only one $a$ per $b$ for the definition of $g$, which makes it a valid function.

    Now we need to prove that $g$ is injective. Suppose $g(b_1) = g(b_2)$ for some $b_1, b_2 \in B$. Let $g(b_1) = a$ (which also means $g(b_2) = a$ too). By definition of $g$, we must have $f(a) = b_1$ and $f(a) = b_2$, which means $b_1 = b_2$. Hence $g$ is injective, completing the forward direction.
\end{proof}

\begin{exercise}[Complete the Proof!]\label{exercise:agreement-of-cardinality-definitions}
    Complete the proof of \myref{theorem:agreement-of-cardinality-definitions}.
\end{exercise}
