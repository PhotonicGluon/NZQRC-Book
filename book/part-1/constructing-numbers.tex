\Chapter{Defining Natural Numbers}
\Lettrine[loversize=0.1,nindent=0pt]{To} define all the numbers, we have to start with the most basic of numbers -- the natural numbers. The natural numbers are the most basic of all numbers. They are considered our counting numbers, and understanding how they can be defined using the axioms of \ZFC~is essential for continuing to create the rest of the numbers.

\section{The Need for Abstraction}
So why go through all this trouble to define the natural numbers? Surely everyone can agree what a natural number is?

Let us ask a simple question: what is 3? Seriously. Think about what 3 really means. In elementary school, we were taught that 3 is just a number quantifying a certain number of things. There are many 3s -- 3 circles, 3 squares, 3 cars, 3 stars, 3 apples, 3 lines, 3 words, 3 points, 3 boxes, etc.
\begin{figure}[H]
    \centering
    \includegraphics[width=8cm]{part-1/constructing-numbers/three.png}
    \caption{Various Examples of 3}
\end{figure}
What they all encapsulate is that there is a certain number of things. And \textbf{that} number is 3. It is an abstraction above a specific `type' of 3. Not 3 circles, or 3 squares, or any of the other types that 3 could be; 3 is a pure symbol symbolising a pure count.

Of course, when it comes to asking what 3 is, at a fundamental level, we need to have a representative for the concept of 3. This is just like how Physics moved away from defining the SI base units using physical objects and their properties, and instead defining them using fundamental physical constants of the Universe. Although they have shifted the burden away from a specific instance of the physical artefact, they still need one for practical use. Likewise, although we can abstract away the idea of 3, we still need a representative for 3.

In this chapter, we will be focusing on defining the natural numbers using a set-theoretic approach. In particular, we will use \ZFC~to construct representatives for \textbf{all} the natural numbers. That way, we will have no ambiguity when we discuss what 3, or 12, or 83, or 1289, or 89338, etc., really means at a fundamental level.

\section{Defining Zero}
The act of defining numbers has to start somewhere. The natural numbers all represent a certain quantity of things -- 3 things, 12 things, 83 things, 1289 things, 89338 things, etc. The problem with defining these other numbers without a good starting point is that there can be an argument of what these numbers really mean at a fundamental level. What is a ``thing''? How do we count these ``things''? How can we ensure that others count these ``things'' the same way? That is why we will start with zero -- the absence of anything.

\begin{figure}[H]
    \centering
    \includegraphics[width=4cm]{part-1/constructing-numbers/counting.png}
    \caption{Counting Down To Zero}
\end{figure}

While other numbers (say 1) can have ambiguity of what they mean (e.g., 1 car, 1 square, 1 point, 1 circle, etc.), 0 necessarily means that there is nothing. It represents the absence of anything, and it does not matter what the type of ``thing'' is. We can agree that, whatever the ``thing'' is, they are not there, and the quantity of that number of items is 0.

Let us appeal to the notion of sets to further elaborate on this. There are many sets that contain 3 items. For example, the sets $\{a, b, c\}$, $\{1, 2, 3\}$, $\{x, y, z\}$, $\{0, 1, 2\}$, $\{+, -, /\}$, and $\{\text{hi}, \text{hello}, \text{bye}\}$ all contain 3 items. But there is one set that contains zero items -- the empty set. Any other set containing zero items must necessarily be the equal to the empty set, since the items in a set uniquely define a set by the \ZFC~axiom of extensionality (\myref{axiom:extensionality}).

As such, we may define the number zero to be the empty set.
\begin{definition}[Zero]\index{zero}
    The number zero is defined to be the empty set. That is,
    \[
        0 = \emptyset.
    \]
\end{definition}
This is definitely a little odd. Why are we defining a number to be a set? Recall that \textbf{everything is a set} under the axioms of \ZFC. Thus every number must necessarily be a set. We might as well define 0, which represents the absence of anything, to be the empty set, the set devoid of everything. Surely any other choice of set that defines 0 would be absurd; why would we pick a non-empty set containing something to represent the lack of anything? Under this light, setting $0 = \emptyset$ is completely natural.

\section{Successor}
Okay, we have defined zero. But what about the rest of the natural numbers?

For the rest of the numbers, our key idea is to use the natural numbers defined before then to define that number itself. That is, to define a natural number $n$, we want to only use the sets 0, 1, 2, \dots, $n-1$ to define $n$. Appealing to the idea that each natural number $n$ should be a set containing $n$ items, it seems natural that we should define
\[
    n = \{0, 1, 2, \dots, n-1\}.
\]
This set contains $n$ items, and so it can be used to represent the natural number $n$.

However, instead of directly defining what $n$ is, we will do it in a more roundabout way -- using something known as the successor of a set.

\begin{definition}[Successor]
    Let $A$ be a set. The \term{successor}\index{successor} of $A$ is
    \[
        \Successor{A} = A \cup \{A\}.
    \]
\end{definition}
In other words, the successor of a set $A$ is the set containing the elements of $A$ and $A$ itself.

\begin{example}[Successor]
    \begin{itemize}[leftmargin=*]
        \item $\Successor{\emptyset} = \emptyset \cup \{\emptyset\} = \emptyset$ since the empty set is, of course, empty.
        \item $\Successor{\{a\}} = \{a\} \cup \{\{a\}\} = \{a, \{a\}\}$.
        \item $\Successor{\{a, b, c\}} = \{a, b, c\} \cup \{\{a, b, c\}\} = \{a, b, c, \{a, b, c\}\}$.
        \item $\Successor{\Successor{\{a\}}} = \Successor{\{a, \{a\}\}} = \{a, \{a\}, \{\{a, \{a\}\}\}\}$.
    \end{itemize}
\end{example}

\begin{exercise}[Successor Practice]
    What is $\Successor{\Successor{\{x, y\}}}$?
\end{exercise}

Usually the successor of a set is only used for defining the natural numbers. Observe that a very nice pattern emerges when we repeatedly find the successor of 0.
\begin{itemize}
    \item $\Successor{0} = \Successor{\emptyset} = \{\emptyset\}$. This set has 1 element.
    \item $\Successor{\Successor{0}} = \Successor{\{\emptyset\}} = \{\emptyset, \{\emptyset\}\}$. This set has 2 elements.
    \item $\Successor{\Successor{\Successor{0}}} = \Successor{\{\emptyset, \{\emptyset\}\}} = \{\emptyset, \{\emptyset\}, \{\emptyset, \{\emptyset\}\}\}$. This set has 3 elements.
\end{itemize}

We see that applying finding the $n$th successor of 0 exactly gives a set with $n$ elements. This repeated application of the successor defines the natural numbers.

\begin{definition}[Defining A Natural Number]
    The natural number\index{natural number} $n$ is defined to be the $n$th successor of 0, and The set that underlies $n$ is called the \term{counter set of $n$}\index{counter set}\index{natural number!counter set}. In other words,
    \[
        n = \overbrace{\Successor{\Successor{\Successor{\cdots\Successor{0}\cdots}}}}^{n \text{ applications}}.
    \]
    Alternatively,
    \[
        n = \begin{cases}
            \emptyset & \text{if } n = 0\\
            \Successor{n-1} & \text{if } n \geq 1
        \end{cases}
    \]
\end{definition}
\begin{remark}[Undefined Operations]
    The alternative definition of $n$ suffers from the fact that we have not yet defined the subtraction (i.e., $-$) and greater-than-or-equals-to (i.e., $\geq$) operations.
\end{remark}

The counter sets of natural numbers can be drawn diagrammatically.
\begin{figure}[H]
    \centering
    \includegraphics[width=5cm]{images/part-1/constructing-numbers/counter-sets.png}
    \caption{The First 5 Counter Sets}
\end{figure}
What we observe is interesting. The counter set of 1 contains the empty set (the counter set of 0), so we may write $1 = \{0\}$. The counter set of 2 contains both the empty set and the counter set of 1, so we may write $2 = \{0, 1\}$. We observe too that $3 = \{0, 1, 2\}$ and $4 = \{0, 1, 2, 3\}$. This observation allows us to make the definition of the natural numbers more concise.

\begin{definition}[Defining A Natural Number, More Concisely]
    Define the natural number
    \begin{itemize}
        \item 0 to be the empty set; and
        \item $n$ to be the set $\{0,1,2,\dots,n-1\}$ for any other natural number $n$.
    \end{itemize}
\end{definition}

\begin{exercise}[Analysing Counter Sets]
    \begin{partquestions}{\roman*}
        \item Write down the counter set of 5 in terms of 0, 1, 2, 3, and 4.
        \item Write down the counter set of 5, using only the curly braces $\{$ and $\}$ and commas.
        \item How many \textbf{open} curly braces (i.e., $\{$) would be used to define the counter set of 65536? Assume we only use the curly braces $\{$ and $\}$ as well as commas.
    \end{partquestions}
\end{exercise}

\section{The Set of Natural Numbers}
With the natural numbers defined, we are almost ready to define the set of natural numbers. However, we need to return back to \ZFC~to include an important axiom.

\subsection{Axiom of Infinity}
As defined so far, \ZFC~does not explicitly state that a set of an infinite number of elements exists. Sure, we can create a set based of a list of items (\myref{theorem:set-of-any-list-of-items}), but this only works for a \textbf{finite} number of items. We can take the union of a list of sets (\myref{theorem:union-of-finite-number-of-sets-exists}), but this works only for a \textbf{finite} number of sets. Regardless of what operations we can do so far, we are limited to a finite number of items and finite sets. Repeatedly applying operations on finite sets will still make the resultant set finite.

Thus, we need to make a leap of faith and bring into existence \textbf{one} infinite set. That is the job of the axiom of infinity -- an infinite set exists.

Loosely, we can state the axiom as
\[
    \exists I ((\emptyset \in I) \land \forall x (x \in I \implies \Successor{x} \in I)),
\]
that is, there exists a set $I$ (an infinite set) such that the empty set is an element of $I$, and, for any element (which is a set, according to \ZFC) in $I$, its successor is also in $I$. One sees that this would mean that there is an infinite number of elements in $I$ -- we can just repeatedly take the successor of elements in $I$ to create something that was not present in $I$. However, this is not stated in our formal language for axiomatic set theory. Can we make it more formal?

The axiom of infinity asserts that an infinite set $I$ exists satisfying the following conditions:
\begin{enumerate}[label=\textbf{I\arabic*.}]
    \item the empty set is an element of $I$;
    \item for any element in $I$, its successor is also in $I$.
\end{enumerate}

Condition \textbf{I1} is easy to state as
\[
    \exists O (O \in I \land \lnot(\exists x (x \in O))).
\]
This states that there is a set $O$ in $I$ such that nothing exists in $O$, which is precisely the definition of the empty set in the axiom of the empty set (\myref{axiom:empty-set}). Note that we use the letter $O$ instead of the standard symbol for the empty set (i.e., $\emptyset$) to avoid confusion.

Condition \textbf{I2} is slightly trickier. Recall that the successor of a set $A$ is the set $A \cup \{A\}$. So an element in the successor must be an element of $A$, or $A$ itself. So if $S$ is the successor of $A$, we can write this down as
\[
    x \in S \iff (x \in A \lor x = A).
\]
Therefore \textbf{I2} can be written as
\[
    \forall x (x \in I \implies \exists S (S \in I \land \forall y (\underbrace{y \in S \iff (y \in x \lor y = x)}_{\text{Definition of Successor}}))).
\]
This means that any element in $I$ must have its successor also in $I$.

We can now put \textbf{I1} and \textbf{I2} together to form the axiom of infinity.

\begin{axiom}[Infinity]\label{axiom:infinity}\index{axiom!infinity}\index{Zermelo-Frankel Set Theory!infinity}
    The infinite set $I$ exists. In particular,
    \begin{align*}
        &\exists I (\\
            &\quad\exists O (O \in I \land \lnot(\exists x (x \in O)))\\
            &\quad\land \forall x (x \in I \implies \exists S (S \in I \land \forall y (y \in S \iff (y \in x \lor y = x))))\\
        &).
    \end{align*}
\end{axiom}

\subsection{A Consequence of the Axiom of Infinity}
It should come as no surprise that the set $I$ that is asserted by \myref{axiom:infinity} is exactly the set of natural numbers. Indeed, \myref{axiom:infinity} states that the empty set (which is the counter set for 0) is in $I$ and that any successor of any set in $I$ also belongs in $I$, which defines the rest of the natural numbers.

\begin{definition}[The Set of Natural Numbers]
    The \term{set of natural numbers}\index{natural number!set}, denoted $\N$, is the set $I$ given by the axiom of infinity (\myref{axiom:infinity}). Equivalently, it is the set containing all the natural numbers, i.e.
    \[
        \N = \{0, 1, 2, 3, 4, 5, \dots\}.
    \]
\end{definition}

One can imagine the size of $\N$ as the set with the `smallest' infinity. Indeed, we will explore other sets with a larger `size' than $\N$ in future parts. But $\N$ is special as it is the only infinite set asserted by an axiom; the rest are all consequences of the \ZFC~axioms, and not an axiom itself.

The rest of this part will be spent exploring the properties of $\N$. We will explore a rigorous definition of counting using natural numbers, comparing the sizes of sets, and defining the operations on $\N$.
