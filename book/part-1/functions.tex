\Chapter{Functions}
\Lettrine[loversize=0.1,nindent=0pt]{Picture} a machine that takes in inputs and produces outputs. It could, for instance, double every number put into it. It may return the sum of all of its inputs, the product of all its inputs, or the largest number among all the inputs. That is what a function is -- a relation that maps inputs to outputs. It is this kind of particular relation that we look at in this chapter.

\section{What is a Function?}
\begin{definition}[Function]\label{definition:function}
    A \term{function}\index{function} $f$ from a set $X$ to a set $Y$ is a relation from $X$ to $Y$ satisfying two properties.
    \begin{enumerate}[label=\textbf{F\arabic*.},leftmargin=1.35\parindent]
        \item $\forall x \in X, \exists y \in Y \text{ s.t. } (x \mathrel{f} y)$
        \item $\forall x \in X, \forall y_1, y_2 \in Y, (((x \mathrel{f} y_1) \land (x \mathrel{f} y_2)) \implies (y_1 = y_2))$
    \end{enumerate}
    We denote such a function by $f: X \to Y$.
\end{definition}

The condition \textbf{F2} essentially says that if a single $x \in X$ is related to two (or more) elements in $Y$, then they must be equal. This can be thought of as the ``uniqueness'' property of a function.

We can succinctly write both \textbf{F1} and \textbf{F2} in one statement using the \term{uniqueness quantifier}\index{uniqueness quantifier}\index{quantifier!uniqueness} $\exists!$. A statement of the form $\exists! x \text{ s.t. } P(x)$, where $P(x)$ is a predicate, is logically equivalent to the statement
\[
    \exists x \text{ s.t. } (P(x) \land (\forall y (P(y) \implies x = y))),
\]
i.e. there exists an $x$ that satisfies the predicate and any $y$ satisfying the predicate must be equal to $x$. Thus, we can combine \textbf{F1} and \textbf{F2} into the single condition
\[
    \forall x \in X, \exists! y \in Y \text{ s.t. } x \mathrel{f} y.
\]
This formulation of the function condition is what we will be using most of the time.

As mentioned, we may think of a function as a machine or process that takes in inputs and produce outputs. In particular, the `machine' for the function $f: X \to Y$ is a machine that \textbf{must} produce an output for any valid input (i.e., an input that comes from $X$) that is provided to it, and it must produce the same output for the same input that is provided to it.

Since there is only one output for any given input, we can denote it unambiguously.

\begin{definition}[Image of an Element Under a Function]\label{definition:image-of-element-under-a-function}
    Let $X$ and $Y$ be sets and $f: X \to Y$ be a function. Suppose $x \in X$. The unique element of $Y$ that is related to $x$ under $f$ is called the \term{image of $x$ under $f$}\index{image!of an element}\index{function!image!of an element} and is denoted $f(x)$.
\end{definition}

Let's now turn our attention to determining the equality of two functions. Recall that two relations $R$ and $S$ from the set $A$ to the set $B$ and the set $C$ to the set $D$ respectively (i.e., $R \subseteq A \times B$ and $S \subseteq C \times D$) are equal if and only if $A = C$, $B = D$, and $R = S$ as sets (\myref{definition:equality-of-relations}). Since functions are also relations, this definition applies to functions.

\begin{definition}[Equality of Functions]\index{function!equality}
    Let $A$, $B$, $C$, and $D$ be sets. The functions $f: A \to B$ and $g: C \to D$ are equal, denoted $f = g$, if and only if $A = C$, $B = D$, and $f = g$ as sets.
\end{definition}

However, we have a more applicable result for functions.
\begin{theorem}[Equality of Functions, More Easily]
    Let $A$, $B$, $C$, and $D$ be sets. Let the functions $f: A \to B$ and $g: C \to D$. Then $f = g$ if and only if $A = C$, $B = D$, and $f(x) = g(x)$ for all $x \in A$.
\end{theorem}
\begin{proof}
    For the forward direction, suppose $f = g$ (as functions). Thus $A = C$, $B = D$, and $f = g$ as sets. Suppose $x \in A$ and $y \in B$ are arbitrary. Note
    \begin{align*}
        & y = f(x)\\
        \iff& (x, y) \in f & (\myref{definition:image-of-element-under-a-function})\\
        \iff& (x, y) \in g & (\text{as } f = g \text{ as sets})\\
        \iff& y = g(x) & (\myref{definition:image-of-element-under-a-function})
    \end{align*}
    which means $f(x) = g(x)$ for any $x \in A$.

    For the reverse direction, suppose $A = C$, $B = D$, and $f(x) = g(x)$ for all $x \in A$. Then
    \begin{align*}
        & (x, y) \in f\\
        \iff& y = f(x) & (\myref{definition:image-of-element-under-a-function})\\
        \iff& y = g(x) & (\text{as } f(x) = g(x)\;\forall x \in A)\\
        \iff& (x, y) \in g & (\myref{definition:image-of-element-under-a-function})
    \end{align*}
    which means that $f = g$ as sets. Thus $f = g$ by definition of equality of functions.
\end{proof}

There are three important sets related to a function.

\begin{definition}[Domain, Codomain, and Range (Functions)]
    Let $X$ and $Y$ be sets and let $f: X \to Y$ be a function.
    \begin{itemize}
        \item The \term{domain}\index{domain}\index{relation!domain} of $f$ is the set $X$.
        \item The \term{codomain}\index{codomain}\index{relation!codomain} of $f$ is the set $Y$.
        \item The \term{range}\index{range}\index{relation!range} of $f$ is the set $\{y \in Y \vert \exists x \in X \text{ s.t. } y = f(x)\}$.
    \end{itemize}
\end{definition}
\begin{remark}[Image of a Function]
    Some authors may call the range of a function the \term{image}\index{image}\index{image!of a function}\index{function!image}\index{function!image!of a function} of the function. However, this would likely lead to confusion with the image of an element under a function, so we will stick with ``range''.
\end{remark}

\section{Axiom Schema of Replacement}
We now look at the axiom schema of replacement.

\subsection{The Need for the Axiom Schema}
We often define functions with a rule. For example, the successor function that is restricted to the natural numbers, i.e. $S: \N \to \N$, is defined by $S(n) = n \cup \{n\}$ for all $n \in \N$. Using relation notation, we can write this as
\[
    n \mathrel{S} m \iff m = n \cup \{n\}.
\]
Another example would be the "character of" function in \myref{example:character-of-function}, where we defined a function $f: N \to C$ (where $N = \{1, 2, 3\}$ and $C = \{+, \text{a}, \text{b}, \text{c}, \text{d}, \text{e}\}$) such that $f(1) = \text{a}$, $f(2) = \text{b}$, and $f(3) = \text{c}$. We can write this as
\[
    x \mathrel{f} y \iff (x = 1 \land y = \text{a}) \lor (x = 2 \land y = \text{b}) \lor (x = 3 \land y = \text{c}).
\]
What these two examples show is that a function $f: X \to Y$ can be defined as
\[
    x \mathrel{f} y \iff P(x, y)
\]
where $P(x,y)$ is a binary predicate.

Essentially, what we want to ensure is that every function's image is indeed a set. Unfortunately, we are unable to quantify over definable functions in our language of axiomatic set theory. So, we are stuck with using an axiom schema that should achieve the same effect.

\subsection{Forming the Axiom Schema}
Let's start with our goal, expressed in a high-level manner: for every function, its range exists. As explained earlier, we are not able to quantify over functions, but we are able to quantify over \wffs~(which include predicates).

Suppose we have a function $f: X \to Y$ such that
\[
    x \mathrel{f} y \iff \phi(x, y, X)
\]
where $\phi$ is a \wff. In essence, the \wff~$\phi$ is the \term{rule}\index{function!rule} of $f$ -- it defines which elements in $Y$ could be an image of an element from $X$. Note that $X$ needs to be a free variable in $\phi$ because the function $f$ may use it to determine which elements are within its range. Now recall that $f$ is a function if and only if
\[
    \forall x \in X, \exists! y \in Y \text{ s.t. } x \mathrel{f} y.
\]
Thus
\[
    \forall x \in X, \exists! y \in Y \text{ s.t. } \phi(x, y, X)
\]
is the condition that must be satisfied for $f$ to be a function. In other words, using semi-formal language, we can write that condition above as
\[
    \forall x (x \in X \implies \exists! y (y \in Y \land \phi(x, y, X))).
\]
Now, for our purposes, we actually want to make the condition a little weaker by removing the need for $y$ to come from a known set $Y$. This is because the axiom itself will bring into existence a set that contains the images of all the elements in $X$, so $y$ just needs to exist. Thus, the antecedent for our condition in the axiom schema of replacement is
\[
    \forall x (x \in X \implies \exists! y \phi(x, y, X)).
\]

We turn our attention to the consequent of the axiom schema of replacement -- that the range of the function $f$ exists. In other words, there must exist a set containing all the images of the elements in $X$, and that any image of an element in $X$ must be in that set. Note that if $y$ is an image of an element in $X$, that means that there exists an $x \in X$ such that $y = f(x)$ (i.e., $x \mathrel{f} y$, or $\phi(x, y, X)$ is true). We can express this idea as
\[
    \exists R \text{ s.t. } \forall y (y \in R \iff \exists x \in X \text{ s.t. } \phi(x, y, X))
\]
where one can interpret $R$ as the range of $f$. Formally, we can write this as
\[
    \exists R \forall y (y \in R \iff \exists x (x \in X \land \phi(x, y, X))).
\]

There are a few more tweaks needed before we can finally arrive at the axiom schema of replacement. First, let us allow $\phi$ to have other free variables other than just $x$, $y$ and $X$. In particular, let $w_1$, $w_2$, \dots, $w_n$ be free variables in $\phi$. So we can write the antecedent and consequent of the axiom schema of replacement semi-formally as
\[
    \forall x (x \in X \implies \exists! y \phi(x, y, w_1, \dots, w_n, X))
\]
and
\[
    \exists R \forall y (y \in R \iff \exists x (x \in X \land \phi(x, y, w_1, \dots, w_n, X)))
\]
for all $X$, $w_1$, $w_2$, \dots, $w_n$. We then combine them into one statement, resulting in the semi-formal statement
\begin{align*}
    &\forall X \forall w_1 \forall w_2 \cdots \forall w_n (\\
    &\quad \forall x (x \in X \implies \exists! y \phi(x, y, w_1, w_2, \dots, w_n, X))\\
    &\hquad\implies \exists R \forall y (y \in R \iff \exists x (x \in X \land \phi(x, y, w_1, w_2, \dots, w_n, X)))\\
    &).
\end{align*}
Lastly, recalling that the uniqueness quantifier is defined such that
\[
    \exists! x \psi(x) \equiv \exists x (\psi(x) \land \forall y (\psi(y) \implies y = x)),
\]
we can finally write state the axiom schema of replacement formally.

\begin{axiom}[Axiom Schema of Replacement]\label{axiom:schema-of-replacement}\index{axiom!schema of replacement}\index{Zermelo-Frankel Set Theory!schema of replacement}
    Let $\phi$ be a \wff. Then
    \begin{align*}
        &\forall X \forall w_1 \forall w_2 \cdots \forall w_n (\\
        &\quad \forall x (x \in X \implies \exists y (\\
        &\quad\quad \phi(x, y, w_1, \dots, w_n, X)\\
        &\quad\quad\land \forall z (\phi(x, z, w_1, \dots, w_n, X) \implies z = y)\\
        &\quad\hquad)\\
        &\quad)\implies \exists R \forall y (y \in R \iff \exists x (x \in X \land \phi(x, y, w_1, \dots, w_n, X)))\\
        &)
    \end{align*}
    where $R$ is not free in $\phi$.
\end{axiom}

This is undoubtedly one of the most involved axiom schema within \ZF, but also one of the most powerful. As we will soon see, functions play a crucial part when working with numbers.

\section{Well-Defined Functions}
\myref{axiom:schema-of-replacement} allows us to assert that the range of any function exists. However, care must be taken to ensure that the rule of the function indeed makes the function a function, and not just a relation. Specifically, referring to \myref{definition:function}, a `function' that fails to satisfy either \textbf{F1} or \textbf{F2} (or both) is called a \term{ill-defined} function, and functions that satisfy both \textbf{F1} and \textbf{F2} are called \term{well-defined} functions (which are actual functions).

\begin{example}[A Possibly Ill-Defined Function]
    Let $S_1$ and $S_2$ be non-empty sets, and let $S = S_1 \cup S_2$. Let $f$ be a relation from $S$ to $\{1,2\}$ such that
    \[
        f = \{(s, 1) \vert s \in S_1\} \cup \{(s, 2) \vert s \in S_2\}.
    \]
    In other words,
    \[
        x \mathrel{f} y \iff (x \in S_1 \land y = 1) \lor (x \in S_2 \land y = 2).
    \]
    Is this a (well-defined) function?

    Suppose $S_1 \cap S_2 = \emptyset$. This means that any element in $S_1$ would have an image of 1, and any element in $S_2$ would have an image of 2. In particular, every element from $S$ will have one and only one image. Thus $f$ is indeed a function. In fact, we can write it using a \term{piecewise definition}\index{piecewise definition}\index{function!piecewise definition} as
    \[
        f(x) = \begin{cases}
            1 & \text{if } x \in S_1\\
            2 & \text{if } x \in S_2
        \end{cases}
    \]

    However, what happens when $S_1 \cap S_2 \neq \emptyset$? Suppose $S_1 = \{1,2\}$ and $S_2=\{2, 3\}$. Then we see
    \[
        f = \{(1, 1), (2, 1), (2, 2), (3, 2)\}.
    \]
    In particular, we see that $2\mathrel{f}1$ and $2\mathrel{f}2$ simultaneously. If we were to abuse some notation, this means that $f(2) = 1$ and $f(2) = 2$ simultaneously. This clearly violates \textbf{F2} in \myref{definition:function}, and thus $f$ is not a (well-defined) function in this case (i.e., $f$ is ill-defined as a function).

    In conclusion, for $f: S \to \{1,2\}$ to be a function such that
    \[
        f(x) = \begin{cases}
            1 & \text{if } x \in S_1\\
            2 & \text{if } x \in S_2
        \end{cases}
    \]
    we must have $S_1 \cap S_2 = \emptyset$.
\end{example}

        \[
            x \mathrel{f} y \iff y = x^3
        \]
        for all $x \in \{1,2,3\}$ and $y \in \{1,8\}$.
        \item The relation $g$ from $\N^2$ to $\N$ such that
        \[

        \]
        for all $x \in \N^2$ and $y \in \N$.
        \item The relation $h$ from $\N$ to $\N^2$ such that
        \[

        \]
        for all $x \in \N$ and $y \in \N^2$.
    \end{partquestions}
\end{exercise}

\section{Injections, Surjections, Bijections}
We now look at two essential properties that functions could satisfy -- injectivity and surjectivity. Bijectivity is just the combination of both injectivity and surjectivity, and it results in the elements of the domain and codomain matching up exactly. Such a bijective function can result in a new function that undoes the original function, called the inverse function.

\subsection{Injectivity}
A function could send multiple elements in the domain to the same element in the codomain. The function's arrow diagram would have two arrows originating at different elements and terminating at the same element. Such a function is \term{non-injective}. It would be nice for a function to have no two distinct elements in the domain map to the same element in the codomain. Diagrammatically, this means that no two arrows originating at different elements terminate at the same element. For example, the ``character of'' function in \myref{example:character-of-function} satisfies this property. Such a function is \term{injective}.

We can express the condition for a function to be injective formally.
\begin{definition}[Injectivity]\index{function!injective}
    Let $X$ and $Y$ be sets, and let $f: X \to Y$ be a function. Then $f$ is \term{injective} if and only if
    \[
        f(x_1) = f(x_2) \implies x_1 = x_2
    \]
    for all $x_1, x_2 \in X$. Equivalently,
    \[
        x_1 \neq x_2 \implies f(x_1) \neq f(x_2)
    \]
    for all $x_1, x_2 \in X$.
\end{definition}

\begin{example}[An Example of Injectivity]
    (\textit{Assume the addition and multiplication of natural numbers is defined.})

    Consider the function $f: \N \to \N$ such that $f(x) = 4x + 1$ for all $x \in \N$. We show that this is injective.
    \begin{proof}
        Suppose $x_1, x_2 \in \N$ such that $f(x_1) = f(x_2)$. By definition of $f$, we have $4x_1 + 1 = 4x_2 + 1$. So $4x_1 = 4x_2$ and thus $x_1 = x_2$. So $f$ is indeed injective by definition.
    \end{proof}
\end{example}

\begin{example}[An Example of Non-Injectivity]
    Consider the function $f: \N \to \N$ such that $f(x) =(\text{last digit of } x)$. We show that this is not injective.
    \begin{proof}
        Note $1 \in \N$ and $11 \in \N$. We see $f(1) = f(11) = 1$, so $f$ is not injective.
    \end{proof}
\end{example}

\subsection{Surjectivity}
Recall that a relation from the set $X$ to the set $Y$ may not have its domain being $X$, but a function has to have its domain to be the entire set $Y$. Likewise, a function's range may not be the whole set $Y$, but it would be nice to have such a function with its range as the codomain. This is the appeal of \term{surjective} functions.

\begin{definition}[Surjectivity]\index{function!surjective}
    Let $X$ and $Y$ be sets, and let $f: X \to Y$ be a function. Then $f$ is surjective if and only if
    \[
        \forall y \in Y, \exists x \in X \text{ s.t. } y = f(x).
    \]
    In other words, every $y \in Y$ has a corresponding $x \in X$, called its \term{preimage}\index{preimage}\index{function!preimage}, such that $y = f(x)$.
\end{definition}

As mentioned, an important property of surjective functions is that their range is their codomain.

\begin{proposition}[Surjective Functions' Range is their Codomain]
    Let $X$ and $Y$ be sets, and let $f: X \to Y$ be a surjective function. Then the range of $f$ is $Y$.
\end{proposition}
\begin{proof}
    Recall that the range of $f$ is the set
    \[
        \{y \in Y \vert \exists x \in X \text{ s.t. } y = f(x)\}.
    \]
    Since $f$ is surjective, every $y \in Y$ has a corresponding preimage $x \in X$ such that $y = f(x)$. Thus the range of $f$ is exactly $Y$.
\end{proof}

    Let's modify the "character of" function in \myref{example:character-of-function} to make it surjective. Let $N$, a subset of the natural numbers, be $\{1, 2, 3, 4, 5\}$ and $C$, a subset of all characters, be $\{\text{b}, \text{c}, \text{d}\}$. Define the function $f: N \to C$ such that
    \[
        f = \{(2, \text{b}), (3, \text{c}), (4, \text{d})\}.
    \]

\begin{example}[A Non-Surjective Function]
    Consider again the successor function restricted to the natural numbers again, i.e. the function $S: \N \to \N$.
