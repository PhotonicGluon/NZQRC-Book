\Chapter{Introduction to Sets}
\Lettrine[loversize=0.1,nindent=0pt]{The} most fundamental object that we will be using in our exploration of the structure of numbers is the set. Sets are omnipresent throughout mathematics, so it is important that one is fluent in the language of sets. This chapter serves as an introduction to sets, as we will be formally defining what they are in a later chapter.

\section{What Are Sets?}
\begin{definition}[A Simple Definition of Sets]
    A \term{set}\index{set} is a collection of things called \term{elements}\index{element} of the set.
\end{definition}

Of course, we will formally define what sets are in a future chapter, but this would suffice for now.

A set is often described by listing elements separated by commas, or by a characterizing property of its elements, within braces ($\{ \ \}$).

\begin{example}[Examples of Sets]
    \begin{itemize}[leftmargin=*]
        \item The collection $\{a, b, c\}$ is a set with 3 elements, namely $a$, $b$, and $c$. This is read ``the set containing the elements $a$, $b$, and $c$''.
        \item The collection $\{2, 3, 4, 5\}$ is a set with 4 elements, namely 2, 3, 4, and 5.
        \item The collection $\{\{1, 2, 3\}, \{4, 5\}, \{6, \{7\}\}\}$ is a set with 3 elements, which are also sets. Namely, it contains the set $\{1, 2, 3\}$, containing the elements 1, 2, and 3, the set $\{4, 5\}$, containing the elements 4 and 5, and the set $\{6, \{7\}\}$, containing the number 6 and the set $\{7\}$ which contains a single element 7.
    \end{itemize}
\end{example}

What if a set has no elements?
\begin{definition}[Empty Set]
    The \term{empty set}\index{set!empty} is the set $\{\}$ and is denoted by $\emptyset$. That is, $\emptyset = \{\}$.
\end{definition}

The empty set will come in useful when we are defining the natural numbers.

Let's now look at set equality.

\begin{definition}[Set Equality]\index{set!equality}
    Two sets $A$ and $B$ are equal if and only if they contain the same elements.
    
    To reflect that the sets $A$ and $B$ are equal to each other, we write $A = B$. If the sets $A$ and $B$ are not equal to each other, we instead write $A \neq B$.
\end{definition}

\begin{example}
    Consider the sets $\{1, 2, 3, 4\}$, $\{4, 3, 2, 1\}$, and $\{3, 4, 1, 2\}$. These sets are equal to each other even though their elements are listed in a different order. Thus we can write
    \[
        \{1, 2, 3, 4\} = \{4, 3, 2, 1\} = \{3, 4, 1, 2\}.
    \]
    However $\{1, 2, 3, 4\}$ and $\{1, 2, 3, 5\}$ are not not equal since the elements in the two sets differ. Hence,
    \[
        \{1, 2, 3, 4\} \neq \{1, 2, 3, 5\}.
    \]
\end{example}

It is important to emphasise that the order of elements in the sets do not matter.

We have specific notation to denote that an object is in a set.

\begin{definition}
    Let $A$ be a set. We write $x \in A$ if and only if $x$ is an element of $A$. Otherwise we write $x \notin A$.
\end{definition}

\begin{example}
    Consider the set $A = \{1, 2, 3\}$. Then clearly 1, 2, and 3 are elements of the set $A$, and so we may write $1 \in A$, $2 \in A$, and $3 \in A$. We could also write this more compactly as $1, 2, 3 \in A$. On the other hand, one sees that 0, -1, and 4 are not elements of the set, so $0 \notin A$, $-1 \notin A$, and $4 \notin A$ (or $0, -1, 4 \notin A$).
\end{example}

To end this section, we introduce the idea of subsets.

\begin{definition}
    Let $A$ and $B$ be sets.
    \begin{itemize}
        \item $A$ is a \term{subset}\index{subset} of $B$ if and only if all elements of $A$ are elements of $B$. This is denoted by $A \subseteq B$.
        \item $A$ is a \term{proper subset}\index{subset!proper} if and only if $A$ is a subset of $B$ and $B$ contains at least one element not in $A$. In this case, we write $A \subset B$.
    \end{itemize}
\end{definition}

\begin{example}
    Consider the sets $A = \{1, 2\}$, $B = \{1, 2, 3\}$, $C = \{1, 4\}$, and $S = \{1, 2, 3\}$. Then $A \subseteq S$ since the elements of $A$, namely 1 and 2, also appear in $S$. Also $B \subseteq S$ since all elements of $B$ appear in $S$. However $C \not\subseteq S$ since 4 is not an element of $S$.

    We note that $B \not\subset S$ since $S$ does not contain an element that is not in $B$. But $A \subset S$ since 3 is not in $A$.
\end{example}

\begin{exercise}
    Let $S$ be a non-empty set where $S \neq \{\emptyset\}$. Determine whether the following are true or false.
    \begin{partquestions}{\alph*}[2]
        \item $\{1, 2\} \subset \{1, 2, 3, 4\}$
        \item $\{1, 2, 3\} \subseteq \{1, 2, 4\}$
        \item $\emptyset \subseteq \emptyset$
        \item $S \subset S$
        \item $S \in \{S, \emptyset\}$
        \item $\{S\} \notin \{S, \emptyset\}$
        \item $S \subseteq \{S, \emptyset\}$
        \item $\{S\} \subseteq \{S, \emptyset\}$
    \end{partquestions}
\end{exercise}
