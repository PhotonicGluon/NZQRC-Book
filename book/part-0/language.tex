\Chapter{The Language of Axiomatic Set Theory}
\Lettrine[loversize=0.1,nindent=0pt]{Writing} clear, concise, and logical sentences is essential in mathematics. We need a consistent way to write statements to arrive at the axioms required for defining the foundations of mathematics. That is a job reserved for formal language, a structure we will explore in this chapter.

\section{An Introduction to Formal Languages}
In English, one may consider a sentence a sequence of words and think of an English word as a sequence of letters. However, not every sequence of letters is a valid word, and not every sequence of words is a grammatically sound sentence. The idea of formal language is to generalise this idea of valid words and valid sentences.

\begin{definition}[Formal Language]\index{formal language}
    A formal language $\Lang$ is a structure comprising two things.
    \begin{itemize}
        \item A set $\Alphabet$ of symbols, called the \term{alphabet} of $\Lang$.
        \item A \term{formal grammar} comprising \term{formation rules} that specify which \term{strings}, which are sequences of symbols from $\Alphabet$, belong to $\Lang$.
    \end{itemize}
\end{definition}

We will explore more about alphabets, strings, formation rules, formal grammar, and their related constructs in the following pages.

\subsection{Alphabets and Strings}
In English, our (primary) alphabet is A to Z, along with the two cases each letter can come in (i.e., uppercase or lowercase). These 54 characters define all the valid letters we can use in English. We use these valid letters to form words via concatenating letters together. Likewise, we can define symbols that make up our alphabet in a formal language and define strings that use the symbols present in our alphabet.

\begin{definition}[Alphabet]
    Let $\Lang$ be a formal language. The \term{alphabet}\index{alphabet}\index{formal language!alphabet} of $\Lang$, usually denoted $\Alphabet$, is the set of symbols used to construct strings in $\Lang$.
\end{definition}

\begin{definition}[String]
    Let $\Lang$ be a formal language. A \term{string}\index{string}\index{formal language!string} is either a finite concatenation of symbols from $\Alphabet$ in $\Lang$ or the empty string $\emptystring$.

    The \term{length}\index{string!length} of a string is the number of symbols making up the string, with the empty string having length 0.
\end{definition}
\begin{remark}[Words]
    Some authors will call strings \term{words}\index{word}\index{formal language!word} formed from $\Alphabet$. However, we will stick with the term ``string'' here as the term ``empty word'' is awkward to use. Also, this may cause confusion with our definition of words later on.
\end{remark}

\begin{example}[A Simple Alphabet]
    Let $\Alphabet = \{a, b\}$. Then $\emptystring$ (the empty string), ``$a$'', ``$b$'', ``$aa$'', ``$ab$'', ``$ba$'', ``$bb$'', ``$aaa$'', ``$aab$'', ``$aba$'', ``$baa$'', etc. are all valid strings. Notice that we have not defined any rules on what strings belong in our formal language -- these are just strings formed from $\Alphabet$.
\end{example}

\subsection{Grammar and Words}
It is undoubtedly unhelpful to say that every string, essentially a combination of letters in our alphabet, is meaningful within our language. In English, for example, the `words' ``hjbhjx'', ``jsadbhf'', and ``jkdswjaaa'' should not count as words! We want to have some restrictions on what strings belong in our formal language and which ones do not. That is the job of formation rules that make up our formal grammar.

\begin{definition}[Formation Rule]
    Let $\Lang$ be a formal language with alphabet $\Alphabet$. A \term{formation rule}\index{formation rule}\index{formal language!formation rule} of $\Lang$ is a rule describing which strings formed from $\Alphabet$ belong to $\Lang$ and which do not. Such strings are called the \term{words}\index{word}\index{formal language!word} of $\Lang$.
\end{definition}
\begin{remark}[Well-Formed Formulae]
    It is common to see words called \term{well-formed formulae}\index{well-formed formulae} (or \term{well-formed formulas}) in other contexts. However, we will stick to using the term ``words'' as this will hopefully reduce the confusion when we actually introduce the well-formed formulae that are in the formal language of axiomatic set theory.
\end{remark}

\begin{definition}[Formal Grammar]
    Let $\Lang$ be a formal language. The \term{formal grammar}\index{formal grammar}\index{formal language!formal grammar} of $\Lang$ is the set of formation rules of $\Lang$.
\end{definition}

With formation rules and formal grammar defined, we can finally look at some examples of formal languages.

\begin{example}[Simple Formal Languages]
    Let $\Alphabet = \{x,y\}$.
    \begin{itemize}[leftmargin=*]
        \item Let $L_1$ be the formal language using the alphabet $\Alphabet$ such that $L_1$ contains strings of length at most 3 and ends with the symbol $y$. Thus one sees that
        \[
            L_1 = \{y, xy, yy, xxy, xyy, yxy, yyy\}.
        \]
        Note that the empty string $\emptystring$ is not a word in $L_1$ since it does not end with the symbol $y$.

        \item Let $L_2$ be the formal language using the alphabet $\Alphabet$ such that $L_2$ contains strings that read the same forwards as they do backwards (i.e., palindromes). So $L_2$ contains at least words
        \[
            \emptystring, ``x'', ``y'', ``xx'', ``yy'', ``xxx'', ``xyx'', ``yxy'', ``yyy'', ``xxxx'',
        \]
        among infinitely many others. Note that the empty string will vacuously belong in $L_2$ since it has no characters and thus read the same forwards as it does backwards.
    \end{itemize}
\end{example}

Before we look at the next example, let us look at the idea of arity.

\begin{definition}[Arity]
    The \term{arity}\index{arity} is the number of arguments or operands taken in by a function or operation. An \term{$n$-ary}\index{$n$-ary} function or operation is a function or operation of arity $n$.
\end{definition}

\begin{example}
    \begin{itemize}[leftmargin=*]
        \item The arity of the function $f(x) = x^2$ is 1 since it only takes in one argument. Thus $f(x)$ is a 1-ary (i.e., \term{uniary}\index{uniary}\index{arity!uniary}) function.
        \item The function $f(x, y, z) = x+yz$ is 3-ary (i.e., \term{ternary}\index{ternary}\index{arity!ternary}) as it takes in three arguments.
        \item The arity of the plus operator is 2 as it takes in two operands. Thus the plus operator is a 2-ary (i.e., \term{binary}\index{binary}\index{arity!binary}) operator.
        \item The arity of a constant (e.g., 3, 7, 11) is 0 since it does not accept any operands/arguments. They can be considered outputs of a 0-ary (i.e., \term{nullary}\index{nullary}\index{arity!nullary}) operation.
    \end{itemize}
\end{example}

Let us now look at a way of writing down expressions without using parentheses. In fact, some programming languages (e.g. Lisp) use a similar format of writing down statements.

\begin{example}[{\L}ukasiewicz Notation]
    \setlength{\parindent}{1.5em}
    Our standard way of writing expressions, such as $a+b$, is said to use infix notation (since the operator sits \textbf{in between} the two operands $a$ and $b$). In 1920, the Polish mathematician Jan
    {\L}ukasiewicz introduced prefix and postfix notation, which we now call \term{{\L}ukasiewicz notation}\index{{\L}ukasiewicz Notation} (or \term{Polish notation}\index{Polish Notation}) and \term{reversed {\L}ukasiewicz notation}\index{{\L}ukasiewicz Notation!reversed} (or \term{reversed Polish notation}\index{Polish Notation!reversed}) respectively. Using our earlier example of $a+b$, it would be written $+ab$ in {\L}ukasiewicz notation and $ab+$ in reversed {\L}ukasiewicz notation. We may add spaces to aid clarity when writing in (reversed) {\L}ukasiewicz notation, i.e. $+\;a\;b$ and $a\;b\;+$.

    We can use formal language to describe {\L}ukasiewicz notation. Suppose we have an alphabet $\Alphabet$ consisting of symbols. Some of these symbols could be operators (e.g., $+$, $-$, $\times$, $\div$). Define non-operator symbols have arity 0 (i.e., nullary). The formal grammar of the formal language $L$ describing {\L}ukasiewicz notation contains only one formation rule as follows.
    \begin{quote}
        If $s \in \Alphabet$ is $n$-ary and $\phi_1, \phi_2, \phi_3, \dots, \phi_n$ are words in $L$, then
        \[
            s\phi_1\phi_2\phi_3\dots\phi_n
        \]
        is also a word in $L$.
    \end{quote}
    Notably, any non-operator symbol is a word in $L$.
    \begin{itemize}
        \item ``$+\;2\;3$'' in $L$ is equivalent to ``$2+3$'' when written in infix notation.
        \item ``$+\;2\;3\;\times\;4$'' in $L$ is equivalent to $(2 + 3) \times 4$ when written in infix notation.
        \item ``$+-\;\div\;2\;3\div\;4\;5\;6$'' in $L$ is the same as ``$((2 \div 3) - (4 \div 5)) + 6$'' when written in infix notation.
    \end{itemize}
\end{example}

        \item Write the expression $4 + ((5 - 6) \times 7)$, which is in infix notation, using {\L}ukasiewicz notation and reversed {\L}ukasiewicz notation, without using brackets (parentheses).
        \item Let $L$ be the formal language for reversed {\L}ukasiewicz notation. What is the formal grammar of $L$?
    \end{partquestions}
\end{exercise}

\section{The Formal Language of Axiomatic Set Theory}
Using formal language when talking about sets helps us alleviate any ambiguity of statements. For the following, let $\SetLang$ denote the formal language of axiomatic set theory.

To start, we need to define the alphabet.

\begin{definition}[The Alphabet of Axiomatic Set Theory]
    The alphabet of $\SetLang$ consist of two main types of symbols.
    \begin{itemize}
        \item \term{Logical Symbols}\index{set formal language!logical symbol}: These symbols have some intrinsic meaning to them. These include
        \begin{itemize}
            \item an infinite set of \term{variables}\index{variable}\index{set formal language!variable}, often denoted by lowercase letters at the end of the English alphabet and can be distinguished using subscripts (e.g., $x$, $y$, $z$, $x_0$, $y_1$, $z_0$), although we may use any English letter if it serves to aid comprehension;
            \item the equality symbol (i.e., $=$), denoting equality;
            \item the logical connectives $\land$, $\lor$, $\lnot$, $\implies$, and $\iff$;
            \item the universal quantifier $\forall$ and the existential quantifier $\exists$; and
            \item parentheses (i.e., $($ and $)$) and other punctuation symbols.
        \end{itemize}
        \item \term{Non-Logical Symbols}\index{set formal language!non-logical symbol}: These represent predicates, functions and constants. In particular,
        \begin{itemize}
            \item for every integer $n \geq 0$ we have an infinite collection of $n$-ary \term{predicate symbols}\index{set formal language!predicate symbol}, which we can write, for example, as
            \[
                P_0^n,\;P_1^n,\;P_2^n,\;P_3^n,\;P_4^n,\;\dots;
            \]
            and
            \item for every integer $n \geq 0$ we have an infinite collection of $n$-ary \term{function symbols}\index{set formal language!function symbol}, which we can write, for example, as
            \[
                f_0^n,\;f_1^n,\;f_2^n,\;f_3^n,\;f_4^n,\;\dots,
            \]
            where the nullary function symbols are called \term{constants}\index{constant}\index{set formal language!constant}.
        \end{itemize}
        If the arity of a non-logical symbol is clear from context, we may elect to omit the superscript.
    \end{itemize}
\end{definition}
\begin{remark}[The Alphabet of First-Order Logic]
    The alphabet defined here is almost the same as the alphabet used in first order logic, except that we include ``$\in$'' in the language.
\end{remark}

Don't worry too much about what functions (and functions symbols) are. For now, one can interpret functions as a black box that takes in a number of inputs (i.e., the arity of the function) and returns a single output. We will cover more about functions when we get to it.

\begin{exercise}[Strings in $\SetLang$]
    Which of the following are strings in $\SetLang$?
    \begin{partquestions}{\alph*}[3]
        \item $x$
        \item $xy$
        \item $xy = x$
        \item $=$
        \item $p \lor q$
        \item $p \land q$
        \item $\implies (p \lnot q)$
        \item $\in \in \in$
        \item $\forall$
        \item $\forall x (\exists y (x \in y))$
        \item $\forall \iff \exists$
        \item $\exists \land \forall \in \lnot ()$
    \end{partquestions}
\end{exercise}

We can now move on to defining the words in $\SetLang$. There are two main types of words in $\SetLang$, namely \term{terms} and \term{well-formed formulae}.

\begin{definition}[Term]
    A \term{term}\index{term}\index{set formal language!term} in $\SetLang$ is formed by applying the following two rules a finite number of times.
    \begin{enumerate}[label=\textbf{T\arabic*.},start=0,leftmargin=1.35\parindent]
        \item Any variable is a term.
        \item If $f$ is an $n$-ary function symbol and $t_1, t_2, \dots, t_n$ are terms, then the string $f(t_1,t_2,\dots,t_n)$ is also a term. In particular, constants are nullary function symbols and thus are terms.
    \end{enumerate}
\end{definition}

\begin{example}[Terms in $\SetLang$]
    \begin{itemize}[leftmargin=*]
        \item The symbols $x$, $y$, $a$, $b$, etc. can all be considered variables and thus are terms by \textbf{T0}.
        \item Suppose $f$ is a binary function symbol and $x$ and $y$ are variables. Thus $f(x,y)$ is a term by \textbf{T0} and \textbf{T1}.
        \item The constants $3$, $7$, $11$, etc. are nullary function symbols and thus are terms by \textbf{T1}.
    \end{itemize}
\end{example}

\begin{definition}[Well-Formed Formula (\wff*)]\label{definition:well-formed-formula}
    A \term{well-formed formula}\index{formula!well-formed}\index{set formal language!well-formed formula} (often abbreviated as \wff\index{wff}\index{set formal language!wff}) in $\SetLang$ is formed by applying the following five rules a finite number of times.
    \begin{enumerate}[label=\textbf{F\arabic*.},leftmargin=1.35\parindent]
        \item If $t_1$ and $t_2$ are terms, then the strings $t_1=t_2$ and $t_1 \in t_2$ are \wff.  % TODO: Check the set inclusion case
        \item If $P$ is an $n$-ary predicate symbol and $t_1, t_2, \dots, t_n$ are terms, then the string $P(t_1,t_2,\dots,t_n)$ is a \wff.
        \item If $\phi$ is a \wff, then the string $\lnot \phi$ is also a \wff.
        \item If both $\phi$ and $\psi$ are \wffs, then the strings $\phi\land\psi$, $\phi\lor\psi$, $\phi\implies\psi$, and $\phi\iff\psi$ are all \wffs.
        \item If $x$ is a variable and $\phi$ is a \wff, then the strings $\forall x\phi$ (meaning ``for all $x$, $\phi$ holds'') and $\exists x\phi$ (meaning ``there exists $x$ such that $\phi$ holds'') are both \wffs.
    \end{enumerate}
\end{definition}

\wffs* that only use the rules \textbf{F1} and \textbf{F2} have a special name.

\begin{definition}[Atomic Formulae]
    A \wff~that uses only the rules \textbf{F1} and \textbf{F2} as described in \myref{definition:well-formed-formula} is called an \term{atomic formula}\index{atomic formula}\index{set formal language!atomic formula}.
\end{definition}

In other words, atomic formulae do not use any binary operators such as $\land$, $\lor$, $\implies$, or $\iff$. They also do not include any quantifiers such as $\forall$ or $\exists$.

In addition, it should be noted that parentheses can be included as appropriate to properly parse \wffs.

\begin{example}[\wffs* in $\SetLang$]
    \begin{itemize}[leftmargin=*]
        \item We know that both $x$ and $y$, as variables, are terms by \textbf{T0}. Thus the strings $x=y$ and $x \in y$ are \wffs~by \textbf{F1}. In fact, both the strings mentioned are atomic formulae.
        \item Suppose $P$ is a predicate symbol and $x$ and $y$ are variables. Thus the string $P(x,y)$ is a \wff~by \textbf{F2}. Notice that the string $P(x,y)$ is also an atomic formula.
        \item Since $x=y$ is a \wff, the string $\lnot(x=y)$, which can also be written as $x \neq y$ in a more familiar notation, is also a \wff~by \textbf{F3}. However the \wff~$\lnot(x=y)$ is not an atomic formula.
        \item As both $x=y$ and $P(x,y)$ are \wffs~by above observations, thus $(x=y)\land P(x,y)$ is also a \wff~by \textbf{F4}. Again, this \wff~is not an atomic formula.
        \item We know that $x=x$ is a \wff. Thus $\forall x(x=x)$ and $\exists x(x=x)$ are both \wffs~(but not atomic formulae) by \textbf{F5}.
    \end{itemize}
\end{example}

\begin{exercise}[What's in $\SetLang$?]
    Characterise the following strings as terms, \wffs, or neither. If the string is a \wff, determine if it is an atomic formula.
    \begin{partquestions}{\alph*}
        \item $f(x,7)$ where $x$ is a variable and the function $f$ is a binary function symbol.
        \item $\forall x (P(x)\iff Q(x,x))$ where $x$ is a variable, $P$ is a unary predicate symbol, and $Q$ is a binary predicate symbol.
        \item $3(f(x))=7$ where $x$ is a variable and the $f$ is a unary function symbol.
        \item $\lnot (\exists x (\forall y (f(x) = f(y))))$ where $x$ and $y$ are variables and $f$ is a unary function symbol.
        \item $\forall x (\exists y (x \in y))$ where $x$ and $y$ are variables.
        \item $P(x=y,x,f(x))$ where $x$ and $y$ are variables, $f$ is a unary function symbol, and $P$ is a ternary predicate symbol.
    \end{partquestions}
\end{exercise}

Notice that variables may appear in \wffs. Some of the variables appear to be `controlled' by, say, a quantifier, while others are not. This is an important observation.

\begin{definition}[Free and Bound Variables]
    Let $x$ be a variable and $\chi$ be a \wff. The variable $x$ is said to be either \term{bound}\index{variable!bound} or \term{free}\index{variable!free} based on the following rules.
    \begin{enumerate}[label=\textbf{V\arabic*.},leftmargin=1.35\parindent]
        \item If $\chi$ is an atomic formula, then $x$ is free in $\chi$ if and only if $x$ appears in $\chi$. There are no bound variables in atomic formulae.
        \item If $\chi$ takes the form $\lnot \phi$ where $\phi$ is a \wff, then
        \begin{itemize}
            \item $x$ is free in $\chi$ if and only if $x$ is free in $\phi$; and
            \item $x$ is bound in $\chi$ if and only if $x$ is bound in $\phi$.
        \end{itemize}
        \item If $\chi$ takes the form $\phi\land\psi$, $\phi\lor\psi$, $\phi\implies\psi$, or $\phi\iff\psi$, where $\phi$ and $\psi$ are \wffs, then
        \begin{itemize}
            \item $x$ is free in $\chi$ if and only if $x$ is free in either $\phi$ or $\psi$; and
            \item $x$ is bound in $\chi$ if and only if $x$ is bound in either $\phi$ or $\psi$.
        \end{itemize}
        \item If $\chi$ takes the form $\forall y \phi$ or $\exists y \phi$, where $y$ is a variable and $\phi$ is a \wff, then
        \begin{itemize}
            \item $x$ is free in $\chi$ if and only if $x$ is free in $\phi$ and $x$ is a different variable from $y$; and
            \item $x$ is bound in $\chi$ if and only if $x$ is bound in $\phi$ or $x$ is the same variable as $y$.
        \end{itemize}
        The variable $y$ is bound in $\chi$.
    \end{enumerate}
\end{definition}

\begin{example}
    \begin{itemize}[leftmargin=*]
        \item Consider the \wff~``$x=y$''. This is an atomic formula, and thus both $x$ and $y$ are free in it by \textbf{V1}.
        \item In the \wff~``$\lnot(x=y)$'', since $x$ and $y$ are both free in the \wff~``$x=y$'', thus both $x$ and $y$ are free in ``$\lnot(x=y)$'' by \textbf{V2}.
        \item The \wff~``$\forall x (x=y)$'' has a bound variable $x$ and a free variable $y$ by \textbf{V4}.
        \item The \wff~``$\exists a (P(x) \implies Q(x, a))$'' has a bound variable $a$ and a free variable $x$ by both \textbf{V3} (applied to the \wff~``$P(x) \implies Q(x, a)$'') and \textbf{V4}.
        \item In the \wff~``$\forall x \forall y \exists z (P(x,y)\implies (Q(x,z) \lor Q(y,z)))$'', the variables $x$, $y$, and $z$ are all bound. Note that the variable $w$ is neither bound nor free since it does not appear in the \wff.
    \end{itemize}
\end{example}

Note that a variable could be both bound and free in the same \wff. This is rare, but possible.

\begin{example}
    Consider the \wff~$P(x) \implies \exists x Q(x)$. On the left side of the \wff, $x$ is free. However, on the right side, $x$ is bound. However, to avoid confusion, we would usually use a different variable to express the existential statement on the right. For example, $P(x) \implies \exists y Q(y)$. Now $x$ is free on both sides of the \wff~(and thus free in the \wff).
\end{example}

\begin{exercise}[Bound and Free Variables]
    In the following \wffs, determine if the variable $x$ is bound, free, both, or neither.
    \begin{partquestions}{\alph*}
        \item $\forall x (\lnot P(x))$ where $P$ is a unary predicate symbol.
        \item $(x=f(y)) \implies \forall x \exists y (y=x)$ where $y$ is a variable and $f$ is a unary function symbol.
        \item $P(x) \implies (\exists y (Q(x, y)))$ where $y$ is a variable, $P$ is a unary predicate symbol, and $Q$ is a binary predicate variable.
        \item $P(a) \implies (P(b) \implies (P(c) \implies P(d)))$ where $a$, $b$, $c$, and $d$ are all variables and $P$ is a unary predicate symbol.
    \end{partquestions}
\end{exercise}

Explicitly stating which variables are free in a \wff~is tedious when there are many variables to list. We have a shorthand for this.

\begin{definition}[\wffs*~with Free Variables]
    Let $\phi$ be a \wff~and let the variables be $x_1, x_2, \dots, x_n$ be free in $\phi$. This fact can be written as $\phi(x_1, x_2, \dots, x_n)$.
\end{definition}

Note that the string ``$\phi(x_1, x_2, \dots, x_n)$'' is \textbf{not} technically a \wff~in $\SetLang$. However, if this string does appear, it means to substitute $\phi$ with its actual statement, replacing the $x_1$, $x_2$, \dots, $x_n$ with the corresponding values as listed in the parentheses. The result of this process will create a \wff.

\begin{example}
    Let $\phi$ be the \wff~``$x=y$''. Note
    \[
        \forall x \phi(x, x)
    \]
    is \textbf{not} technically a \wff. However, using our interpretation above, we will substitute the appropriate variables to get
    \[
        \forall x (x=x)
    \]
    which is a \wff.
\end{example}
