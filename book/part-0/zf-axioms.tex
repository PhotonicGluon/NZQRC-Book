\Chapter{Axiomatic Set Theory}
\Lettrine[loversize=0.1,nindent=0pt]{Paradoxes} are the bane of creating a consistent system in mathematics. However, set theory, as we have introduced it, is full of paradoxes. For example, as stated so far, a set could contain itself. However, this leads to Russell's paradox of the set of all sets that are not members of themselves. To that end, we look at a more axiomatic definition of what sets are, inspired by the work of Ernst Zermelo and Abraham Fraenkel, to create a system that is (hopefully) devoid of paradoxes.

\section{An Introduction to Zermelo-Fraenkel Set Theory}
The modern study of set theory was initiated by Richard Dedekind and Georg Cantor in the 19th century. Unfortunately, these early systems are rife with paradoxes, prompting the creation of more robust axiomatic systems. Zermelo-Fraenkel set theory\index{Zermelo-Frankel Set Theory} (often abbreviated as \ZF\index{ZF}) is the most is still the best-known and most studied, and it will be what we use to define numbers from the ground up.

\ZF~has 9 main axioms.

\begin{enumerate}
    \item \textbf{Axiom of Extensionality}: Two sets are equal if they have the same elements.
    \item \textbf{Axiom of the Empty Set}: The empty set exists.
    \item \textbf{Axiom of Pairing}: Any two objects have a pair.
    \item \textbf{Axiom of Union}: The union of the elements in a set exists.
    \item \textbf{Axiom of Power Set}: The power set of a set exists.
    \item \textbf{Axiom Schema of Specification}: An axiom describing how a set can be created using set-builder notation.
    \item \textbf{Axiom Schema of Replacement}: The image of any function exists.
    \item \textbf{Axiom of Foundation}: Every non-empty set $A$ contains an element $B$ which is disjoint from $A$. This is used to prevent paradoxes about sets containing themselves.
    \item \textbf{Axiom of Infinity}: An infinite set exists.
\end{enumerate}
\begin{remark}[Axiom of Choice]
    There is a controversial tenth axiom, called the \textbf{Axiom of Choice}. Essentially, it states that a Cartesian product of a collection of non-empty sets is non-empty. This also includes sets that are infinite. \ZF~with the axiom of choice included is usually denoted \textsf{ZFC}\index{ZFC}. However, for our exploration of number here, we do not require the axiom of choice.    
\end{remark}
\begin{remark}[Choice of Axioms]
    Apart from the controversial axiom of choice, the names and statements of the axioms in \ZF~are, frustratingly, inconsistent.
    \begin{itemize}
        \item Some authors call the axiom schema of specification the axiom of subsets.
        \item Some call the axiom of foundation the axiom of regularity.
        \item Many authors will group the axiom of the empty set along with the axiom of infinity.
    \end{itemize}
    The 9 axioms that we look here are what should be the most illuminating and essential ones.
\end{remark}

An important thing to note when we are working in \ZF~is that \textbf{everything is a set}. The foundational object that we are discussing is the set, and we are defining everything in terms of sets. We are simply specifying that the properties of these objects (sets) are. Thus awkward notation like $a \in b$ or $1 \cup 2$ is readily explained way when we remember that all objects are sets.

\section{Axiom of Extensionality}
The first axiom that we will look at is the axiom of extensionality.

\begin{axiom}[Extensionality]\label{axiom:extensionality}\index{axiom!of extensionality}\index{Zermelo-Frankel Set Theory!extensionality}
    \[
        \forall A \forall B \left(\forall x \left((x \in A \iff x \in B) \implies A = B\right)\right)
    \]
\end{axiom}

Let us understand what this means. For all $A$ and $B$, remembering the golden rule that everything is a set, if for all $x$, $x$ is a member of $A$ if and only if $x$ is a member of $B$, then $A$ and $B$ are equal. In other words, if any element in $A$ is in $B$, and vice versa, then $A$ and $B$ are equal, and this holds for all sets.

Some may interpret this axiom as the foundational property of sets. Sets are equal if they have the same members. That is what all they are. All the other axioms simply tell us what sets exist.

\section{Axiom of the Empty Set}
The next axiom starts to give us an idea of what sets could exist.

\begin{axiom}[Empty Set]\label{axiom:empty-set}\index{axiom!empty set}\index{Zermelo-Frankel Set Theory!empty set}
    \[
        \exists A (\lnot \exists x (x \in A))
    \]
\end{axiom}

Simply put, there exists a set $A$ such that there does not exist an $x$ that is in $A$. This applies to all $x$, meaning that there must be nothing in $A$. Hence we see that $A$ is the empty set $\emptyset$.

\section{Axiom of Pairing}
The axiom of pairing gives us another example of what sets exist.

\begin{axiom}[Pairing]\label{axiom:pairing}\index{axiom!of pairing}\index{Zermelo-Frankel Set Theory!pairing}
    \[
        \forall x \forall y \exists S \left(\forall z \left(z \in S \iff ((z = x) \lor (z = y))\right)\right)
    \]
\end{axiom}

In English, this means that for all $x$ and $y$, there exists a set $S$ such that any element $z$ in $S$ must be either $x$ or $y$. Clearly, this must mean that the set $S$ in question is the set containing only $x$ and $y$, i.e. the set $\{x, y\}$. This is why this is called the axiom of pairing -- it guarantees that the unordered pair exists.

We now consider sets with one element.

\begin{definition}[Singleton]
    A \term{singleton}\index{singleton} is a set containing one element. We denote a singleton containing the element $x$ by $\{x\}$.
\end{definition}

\myref{axiom:pairing} allows us to definitively prove within \ZF~that singletons exist.

\begin{proposition}[Singletons Exist]\label{prop:singletons-exist}
    Singletons exist. Formally,
    \[
        \forall x \exists S \left(\forall z \left(z \in S \iff z = x\right)\right).
    \]
\end{proposition}
\begin{proof}
    \myref{axiom:pairing} says that
    \[
        \forall x \forall y \exists S \left(\forall z \left(z \in S \iff ((z = x) \lor (z = y))\right)\right).
    \]
    In particular we may choose $y = x$. Thus the statement reduces to
    \[
        \forall x \exists S \left(\forall z \left(z \in S \iff z = x\right)\right)
    \]
    as required.
\end{proof}

\myref{axiom:pairing} also allows us show that sets have `no repeated elements'. For example, we can show that the sets $\{a, a\}$ and $\{a\}$ are the same set.

\begin{proposition}[The `No Repeated Elements' Property]\index{no repeated elements}
    $\{a, a\} = \{a\}$ for all $a$. Formally,
    \[
        \forall a (\{a,a\} = \{a\}).
    \]
\end{proposition}
\begin{proof}
    First, note for any $a$ that the sets $\{a, a\}$ and $\{a\}$ do indeed exist by \myref{axiom:pairing} and \myref{prop:singletons-exist} respectively. Next, recall that \myref{axiom:extensionality} tells us that
    \[
        \forall A \forall B \left(\forall x \left((x \in A \iff x \in B) \implies A = B\right)\right).
    \]
    In particular, let $A = \{a, a\}$ and $B = \{a\}$.
    \begin{itemize}
        \item If $x \in A$, then $x$ is forced to be $a$. Clearly this means that $x \in B$.
        \item If $x \in B$, then $x$ is either $a$ (the first one) or $a$ (the second one). In either case we have $x = a$. Thus $x \in A$ also.
    \end{itemize}
    Hence the condition ``$x \in A \iff x \in B$'' is satisfied. So that axiom tells us that $A = B$, i.e. $\{a, a\} = \{a\}$.
\end{proof}

\section{Axiom of Union}
Remember how we can take the union of sets? This next axiom explicitly gives us that operation within \ZF.

\begin{axiom}[Union]\label{axiom:union}\index{axiom!union}\index{Zermelo-Frankel Set Theory!union}
    \[
        \forall A \exists U \forall x (x \in U \iff \exists S ((x \in S) \land (S \in A)))
    \]
\end{axiom}

We can interpret this in English as saying that given any set $A$, there exists a set $U$ (the union) such that any element $x$ in $U$ must be in some set $S$ in $A$ (recalling that everything is thought of as a set in \ZF).

The combination of \myref{axiom:pairing} and \myref{axiom:union} allows us to create a set from an arbitrary list of items.

\begin{theorem}[Set of Any List of Items]\label{theorem:set-of-any-list-of-items}
    For any $a_1, a_2, \dots, a_n$, the set $\{a_1, a_2, \dots, a_n\}$ exists.
\end{theorem}
\begin{proof}
    See \myref{exercise:set-of-any-list-of-items} (later).
\end{proof}
\begin{remark}[Infinite Sets]
    Note that the theorem only works for a finite number of items. The argument by induction does not work for an infinite number of items, which is partly the reason why we need to define the axiom of infinity (to be introduced later).
\end{remark}

A related result is the union of an arbitrary (but finite) number of sets.

\begin{theorem}[Union of Finite Number of Sets Exists]\index{theorem:union-of-finite-number-of-sets-exists}
    For any finite number of sets $A_1, \dots, A_n$, the set
    \[
        \bigcup_{i=1}^n A_i = A_1 \cup A_2 \cup \cdots \cup A_n
    \]
    exists.
\end{theorem}
\begin{proof}
    We consider induction on $n$.

    The base case when $n = 1$ is trivial since $\bigcup_{i=1}^n A_i = A_1$ exists.

    Suppose the induction hypothesis holds for some number of sets $k \geq 1$, i.e. the set $\bigcup_{i=1}^k A_i$ exists for any sets $A_1$, \dots, $A_k$. We show that the set $\bigcup_{i=1}^{k+1} A_i$ exists for any sets $A_1$, \dots, $A_k$, $A_{k+1}$.              
    
    By induction hypothesis the set $\bigcup_{i=1}^k A_i$ exists. By \myref{axiom:pairing} we can form a set
    \[
        \left\{\bigcup_{i=1}^k A_i, A_{k+1}\right\}.
    \]
    Thus by \myref{axiom:union}, the set
    \[
        \left(\bigcup_{i=1}^k A_i\right) \cup A_{k+1} = \bigcup_{i=1}^{k+1} A_i
    \]
    exists, proving the case for $k+1$.

    Hence, by mathematical induction, the theorem is proven.
\end{proof}

\section{Axiom of Power Set}
The power set is the set of all subsets of a set. This set is explicitly instantiated for all sets in \ZF~via the axiom of power set.

\begin{axiom}[Power Set]\label{axiom:power-set}\index{axiom!power set}\index{Zermelo-Frankel Set Theory!power set}
    \[
        \forall A \exists P \forall S (S \in P \iff \forall x (x \in S \implies x \in A))
    \]
\end{axiom}

In other words, for any set $A$ there is a set $P$ (the power set of $A$) such that for all sets $S$ in $P$, any element in $S$ is also in $A$. This clearly must mean that $S$ is a subset of $A$ and thus $P$, being the collection of all such subsets, is the power set $\Power{A}$.

This axiom, along with \myref{axiom:union}, can be used to prove that the Cartesian product exists. Recall that the Cartesian product of two sets $A$ and $B$ is the collection of 2-tuples where the first element comes from $A$ and the second comes from $B$.

\begin{lemma}[Cartesian Product of Two Sets is a Set]\label{lemma:cartesian-product-of-two-sets-is-a-set}
    Let $A$ and $B$ be non-empty sets. Then their Cartesian product,
    \[
        A \times B = \{(a, b) \vert a \in A \land b \in B\},
    \]
    is indeed a set. In particular, it is a subset of $\Power{\Power{A\cup B}}$.
\end{lemma}
\begin{proof}
    We just need to show that the collection of all ordered pairs is indeed a set. Let $a \in A$ and $b \in B$. Note \myref{axiom:union} says that the union of $A$ and $B$ (i.e., the set $A \cup B$) exists. Thus one sees clearly that $a, b \in A \cup B$.

    Now \myref{prop:singletons-exist} tells us that the set containing only $a$ (i.e., $\{a\}$) exists. Furthermore \myref{axiom:pairing} tells us that the set containing only $a$ and $b$ (i.e., $\{a, b\}$) exists. Clearly both $\{a\}$ and $\{a, b\}$ are subsets of $A \cup B$. Since the power set of $A \cup B$ (i.e., $\Power{A \cup B}$) exists by \myref{axiom:power-set}, thus we can write $\{a\}, \{a, b\} \in \Power{A \cup B}$.

    Recall that the ordered pair $(a, b)$ is defined to be the set $\{\{a\}, \{a, b\}\}$. One sees that
    \[
        \{\{a\}, \{a, b\}\} \in \Power{\Power{A \cup B}}.
    \]
    and so $(a, b) = \{\{a\}, \{a, b\}\}$ exists and is an element of $\Power{\Power{A \cup B}}$. Thus the collection of all such $(a,b)$ is indeed a set by \myref{axiom:union}.
\end{proof}

With this result we can prove that the more general Cartesian product exists.

\begin{theorem}[Cartesian Product is a Set]
    Let $A_1, A_2, \dots, A_n$ be non-empty sets where $n \geq 2$. Then the Cartesian product $A_1 \times A_2 \times \cdots \times A_n$ is indeed a set.
\end{theorem}
\begin{proof}
    We make the following claim.
    \begin{quote}
        The Cartesian product of the sets $A_1, A_2, \dots, A_n$ is a subset of $\Power{\Power{A_1 \cup A_2 \cup \cdots \cup A_n}}$.
    \end{quote}
    We will prove this using induction on $n$, which will immediately prove the theorem.

    The base case of $n = 2$ is given by \myref{lemma:cartesian-product-of-two-sets-is-a-set}.

    Now assume that the induction hypothesis holds for some $k \geq 2$, i.e. the Cartesian product $A_1 \times \cdots \times A_k$ is a subset of $\Power{\Power{A_1 \cup \cdots \cup A_k}}$. We will show that the Cartesian product $A_1 \times \cdots \times A_k \times A_{k+1}$ is a subset of $\Power{\Power{A_1 \cup \cdots \cup A_k \cup A_{k+1}}}$.

    We know that $\{a_1\}, \{a_1, a_2\}, \{a_1, a_2, a_3\}, \dots, \{a_1, a_2, \dots, a_k\} \in \Power{A_1 \cup A_2 \cup \cdots \cup A_k}$ from the induction hypothesis. Note that $A_1 \cup \cdots \cup A_k \cup A_{k+1}$ exists by \myref{axiom:union}, and that $a_1, \dots, a_k, a_{k+1} \in A_1 \cup \cdots \cup A_k \cup A_{k+1}$.

    Note that $\{a_{k+1}\}$ and $\{a_1, a_2, \dots, a_k\}$ are both subsets of $\Power{A_1 \cup \cdots \cup A_k \cup A_{k+1}}$, where the former exists due to \myref{prop:singletons-exist} and the latter exists due to the induction hypothesis. Hence their union, namely $\{a_1, a_2, \dots, a_k, a_{k+1}\}$, exists, and is a member of $\Power{A_1 \cup \cdots \cup A_k \cup A_{k+1}}$.

    Therefore, the object
    \[
        \{\{a_1\}, \{a_1, a_2\}, \{a_1, a_2, a_3\}, \dots, \{a_1, a_2, \dots, a_k\}, \{a_1, a_2, \dots, a_k, a_{k+1}\}\},
    \]
    which is $(a_1, \dots, a_k, a_{k+1})$, is a set. In particular, it is in $\Power{\Power{A_1 \cup \cdots \cup A_k \cup A_{k+1}}}$. Therefore the collection of all such objects, i.e. the Cartesian product $A_1 \times \cdots \times A_k \times A_{k+1}$, exists because it is a subset of $\Power{\Power{A_1 \cup \cdots \cup A_k \cup A_{k+1}}}$.
\end{proof}

\section{Axiom Schema of Specification}  % aka Axiom of Subsets
The axiom schema of specification, also known as the axiom of subsets\index{axiom!of subsets}, allows us to restrict the elements of a set to those that satisfy a specific condition.

\begin{axiom}[Schema of Specification]\index{axiom!schema of specification}\index{Zermelo-Frankel Set Theory!schema of specification}
    Let $\phi$ be a \wff. Then
    \begin{align*}
        &\forall A \forall w_1 \forall w_2 \cdots \forall w_n \exists S(\\
        &\quad\quad\forall x \left(x \in S \iff (x \in A \land \phi(x, w_1, w_2, \dots, w_n, A))\right)\\
        &)
    \end{align*}
    where $S$ is not free in $\phi$.
\end{axiom}

In other words, for every set $A$ and for every $w_1$ to $w_n$ there exists a set $S$ such that $x$ is in $S$ if and only if $x$ is in $A$ and that $\phi$ is satisfied.

Note that we require one instance of the above for every \wff~$\phi$. Thus, this is an axiom schema and not just an axiom.
